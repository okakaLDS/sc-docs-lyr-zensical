# システム化の背景・目的 — 使い方

*記入用の様式は [空テンプレート](<[Template]2-1_システム化の背景・目的.md>)、記入例は [サンプル](<[Sample]2-1_システム化の背景・目的.md>) を参照。*

## 1. 参考様式

*全注（全注文システム）基本設計書 `Ⅰ-1.ｼｽﾃﾑ化の背景・目的.xls` の構成に合わせている。
見出し番号・表の列は全注の実ファイルのものを踏襲している。本システムで不要な列は削ってよい。*

## 2. 各節に書くこと

| 節 | 書くこと |
| -- | -------- |
| 1. システム化の背景 | 現行業務がどう回っていて、何が問題になっているかを記述する（例：台帳管理が属人化している、負荷が大きい 等）。業務が複数あるときは 1-1、1-2… の小節に分け、必要な小節に導入前の業務フロー図（記法は 3.1 業務フローと同じ `sequenceDiagram`）と「導入前の運用」の表を置く |
| 2. システム化の目的 | システム化によって何を達成するのかを記述する |
| 3. 導入前とシステム化後の比較 | 業務ごとに「導入前（手作業）／課題／システム化後」を 1 行で対比する。節1 の図・文章の要約であり、正確な情報はこの表で持つ（記述ルール 節3 No.5） |
| 4. 対応方針 | 目的を達成するための方針を ①②③… の単位で記述する。具体的な開発方針は 2.2 開発方針を正とし、ここでは要点のみ |
