# 開発方針 — 使い方

*記入用の様式は [空テンプレート](<[Template]2-2_開発方針.md>)、記入例は [サンプル](<[Sample]2-2_開発方針.md>) を参照。*

## 1. 参考様式

*全注（全注文システム）基本設計書 `Ⅰ-2.開発方針.xlsx` の構成に合わせている。
見出し番号・表の列は全注の実ファイルのものを踏襲している。本システムで不要な列は削ってよい。*

## 2. 各節に書くこと

| 節 | 書くこと |
| -- | -------- |
| 1. システム化における重要ポイント | 業務改善要望のうちシステム化するものを列挙。既存システムとの共存・権限制御・他システムとの整合など、設計全体を縛る前提もここに書く |
| 2-1. 業務目標／機能目標 | システム化で達成する業務上・機能上の目標を ①②… で書く |
| 2-2. 性能目標 | レスポンス等の目標。**詳細は [レスポンス一覧（6.9）](<../../06-システム設計書（一覧、管理台帳）/6-9_レスポンス一覧/[Template]6-9_レスポンス一覧.md>) が正**。本書には代表値のみ |
| 3. データ増加量 | テーブルごとの想定増加量を見積もる（全注は「データ増加量算出」シートで算出） |
