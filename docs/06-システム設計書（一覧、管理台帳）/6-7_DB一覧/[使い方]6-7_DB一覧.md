# DB一覧 — 使い方

*記入用の様式は [空テンプレート](<[Template]6-7_DB一覧.md>)、記入例は [サンプル](<[Sample]6-7_DB一覧.md>) を参照。*

## 1. 参考様式

*全注（全注文システム）基本設計書 `Ⅴ-6.DB一覧.xlsx` の構成に合わせている。
見出し番号・表の列は全注の実ファイルのものを踏襲している。本システムで不要な列は削ってよい。*

## 2. 記載のルール

| No. | 項目 | ルール |
| --- | ---- | ------ |
| 1 | 単位 | **1行＝1テーブル（またはビュー）**。テーブルIDをキーとする |
| 2 | 区分・スキーマは列で持つ | 原本は「業務／共通機能／システム」の3シート＋グループ見出し行で分けていたが、本サイトでは**1つの表に統合し、区分・スキーマを列**にする（見出し行は並べ替え・抽出で消え、AIも誤読するため） |
| 3 | レイアウトとの対応 | **1テーブル＝1レイアウト定義**。各行から [DBレイアウト](<../../07-データベース・ファイル設計書/7-1_DBレイアウト/[Template]{テーブルID}_{テーブル名}.md>) 配下の該当ページへリンク |
| 4 | ER図との整合 | [DB関連図（ER図）](<../../07-データベース・ファイル設計書/7-3_DB関連図（ER図）/[Template]7-3_DB関連図（ER図）.md>) に登場するテーブルは必ず本表に行があること |
| 5 | 整理・保有期限の正 | テーブルの整理・保有期限は**本表を正**とする（ファイルは [ファイル一覧](<../6-5_ファイル一覧/[Template]6-5_ファイル一覧.md>) と使い分ける） |
| 6 | 整理条件の特記 | 条件付きの整理（「※1注文に対し納期リビジョンが100超で古いものから整理」等）は備考に条件ごと書く |

## 3. 凡例

| 列 | 値の例 | 意味 |
| -- | ------ | ---- |
| 区分 | `業務` / `共通機能` / `システム` | テーブルの管轄（原本の3シートに対応） |
| 分類 | `累積(A)` / `データ(D)` / `マスター(M)` / `トランザクション(V)` / `ビュー(V)` | テーブルの性質（括弧内はテーブルIDの種別文字と対応） |
| 整理 | `なし` / `随時` / `バッチで削除` | 整理の方法 |
| 保有期限 | `永久` / `1年` / `※`（備考参照） | データを保持する期間 |
| メンテナンス対象 | `●` / `-` | 顧客（SC様）が画面等から直接メンテナンスするマスターか |
