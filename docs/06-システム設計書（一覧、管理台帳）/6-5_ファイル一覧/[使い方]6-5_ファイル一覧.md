# ファイル一覧 — 使い方

*記入用の様式は [空テンプレート](<[Template]6-5_ファイル一覧.md>)、記入例は [サンプル](<[Sample]6-5_ファイル一覧.md>) を参照。*

## 1. 参考様式

*全注（全注文システム）基本設計書 `Ⅴ-4.ﾌｧｲﾙ一覧.xlsx` の構成に合わせている。
見出し番号・表の列は全注の実ファイルのものを踏襲している。本システムで不要な列は削ってよい。*

## 2. 記載のルール

| No. | 項目 | ルール |
| --- | ---- | ------ |
| 1 | 単位 | **1行＝1ファイル**。ファイルIDをキーとする |
| 2 | ファイル名と物理ファイル名 | **別の列に分ける**（原本は1セル2段書きだが、検索・抽出のため列を分離） |
| 3 | 物理ファイル名 | 命名規則ごと書く（例: `FAZS121_yyyyMMddhhmmssSSS.tsv`）。可変部分は書式で示す |
| 4 | レイアウトとの対応 | **1ファイル＝1レイアウト定義**。各行から [ファイルレイアウト](<../../07-データベース・ファイル設計書/7-2_ファイルレイアウト/[Template]{ファイルID}_{ファイル名}.md>) 配下の該当ページへリンク |
| 5 | 機能IDの整合 | [システム機能一覧](<../6-1_システム機能一覧/[Sample]6-1_システム機能一覧.md>) と一致させる |
| 6 | 同一レイアウトの使い回し | 別ファイルが同じレイアウトを使う場合、行は分けたうえで補足説明に「レイアウトは `FAZS121` と同一」のように書く |
| 7 | SQL出力ファイル | データをSQL文（INSERT等）で書き出す `.sql` は、レイアウト列から [ファイルレイアウト](<../../07-データベース・ファイル設計書/7-2_ファイルレイアウト/[Template]{ファイルID}_{ファイル名}.md>)（「SQL出力仕様」）へリンクする。**CREATE等のDDL・プロシージャー実行など「処理」のSQLはレイアウト対象外**。本表には「SQLスクリプト（レイアウト対象外）」として1行登録し、レイアウト列は [DB(SQL)処理定義書（8.3）](<../../08-システム機能設計書/8-3_DB(SQL)処理定義書/[使い方]DB(SQL)処理定義書.md>) へリンクする |
| 8 | 生成元 | 「生成元」には**このファイルを書き出すもの**を書く。画面が作るファイルは機能ID、バッチが作るファイルは [バッチ一覧](<../6-3_バッチ一覧/[Sample]6-3_バッチ一覧.md>)（6.3）のバッチファイル名（[バッチ処理定義書](<../../08-システム機能設計書/8-2_バッチ処理定義書/[使い方]バッチ処理定義書.md>)（8.2）が作成済みならそのフォルダーへリンク）、外部システムから受領するファイルは連携元システム名（[IF一覧](<../6-6_IF一覧/[Sample]6-6_IF一覧.md>)（6.6）と一致させる）。バッチファイル名は [タイムチャート](<../../09-運用設計/9-2_タイムチャート/[Sample]9-2_タイムチャート.md>)（9.2）節2 の表記と ID 部分を一致させ、起動タスクは 9.2 をそのバッチ名で検索して辿る（本表に起動タスク列は持たない） |
| 9 | ログファイル | バッチ・画面が出すログも**本表に載せる**（分類 `ログ`）。ログはファイルIDを持たないのでファイルIDは `-` とし、行は物理ファイル名で識別する。バッチのログは機能ID・機能名称も `-`、レイアウトは `-`（7-2 の対象外）。補足説明に何が書かれるか（実行ログか SQL\*Loader のロードログか、上書きか追記か）を書く。1 つのバッチが複数のログを出す場合は行を分ける |

> **📌 「整理」「保存期限」の正は本ドキュメント**
>
> *ファイルごとの整理（削除・アーカイブ）と保存期限は**本表を正**とする。
> [運用方針](<../../09-運用設計/9-1_運用方針/[Template]9-1_運用方針.md>) 側にも保持方針の記述があるが、
> あちらは DB ダンプ等のシステム系ファイルと全体方針のみを扱い、
> 業務データファイル・ログの個別値は本表を参照する（二重管理を避けるため）。*

## 3. 凡例

| 列 | 値の例 | 意味 |
| -- | ------ | ---- |
| 分類 | `データ` / `ログ` / `一時` | ファイルの性質 |
| 生成元 | `S001A` / `goFVAAD51.bat` / `全注文システム` | 画面の機能ID／バッチファイル名／連携元システム名 |
| 整理 | `不要` / `随時` / `バッチで削除` | 整理（削除・アーカイブ）の方法 |
| 保存期限 | `なし` / `無期限` / `1年` | 保存する期間 |
