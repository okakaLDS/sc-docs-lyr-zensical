# 採番一覧 — 使い方

*記入用の様式は [空テンプレート](<[Template]6-8-1_採番一覧.md>)、記入例は [サンプル](<[Sample]6-8-1_採番一覧.md>) を参照。*

## 1. 参考様式

*全注（全注文システム）基本設計書 `Ⅴ-7-01.採番一覧.xls` の構成に合わせている。
見出し番号・表の列は全注の実ファイルのものを踏襲している。本システムで不要な列は削ってよい。*

## 2. 記載のルール

| No. | 項目 | ルール |
| --- | ---- | ------ |
| 1 | 単位 | **1採番対象＝1節**。採番対象ごとの詳細を書き、節1の一覧から辿れるようにする |
| 2 | 体系の書き方 | **構成式**（`固定① + システム日付(yyMMdd) + 連番①(3桁)`）と**桁内訳表**（桁数・値の範囲・リセット単位）の両方を書く。構成式は全体把握用、内訳表は値の妥当性確認用 |
| 3 | 採番マスターとの対応 | システム採番の場合、採番マスターの識別コードを必ず併記する（実装と突き合わせるため） |
| 4 | 桁数の根拠 | 想定件数と採番容量を比較し、桁数が足りる根拠を書く |

## 3. 各節の書き方

| 節 | 書くこと |
| -- | -------- |
| 採番方針 | なぜその採番体系にするのかを①②③で。「どう採番するか」だけでなく**「なぜそうするか」**を残す（後の変更判断に必要）。全注ではBCP（障害時の手動採番）・一意性（連携キー）・連携先の文字種桁数遵守などが挙がっていた |
| 採番体系 | 構成式＋桁内訳表。可変部分は `yyMMdd` 等の書式で示す |
| 固定値・区分値 | 固定パートの値と意味。状態（ドラフト／確定）や種別を桁に埋め込む場合はここで定義。採番マスター識別コードを併記 |
| 桁数の妥当性 | 想定件数に対して採番容量が足りることを確認する |
| 手動採番・例外 | システム障害時などにシステムを介さず採番する場合のルールと、機械的に紐づかないデータの扱い（全注はAA〜ZZを手動採番専用枠にしていた） |
