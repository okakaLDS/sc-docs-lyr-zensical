# レスポンス一覧 — 使い方

*記入用の様式は [空テンプレート](<[Template]6-9_レスポンス一覧.md>)、記入例は [サンプル](<[Sample]6-9_レスポンス一覧.md>) を参照。*

## 1. 参考様式

*全注（全注文システム）基本設計書 `Ⅴ-8. ﾚｽﾎﾟﾝｽ一覧.xlsx` の構成に合わせている。*

## 2. 記載レベル（本プロジェクトは B に決定）

> **📌 本プロジェクトは記載レベル B（現行実測を基準）で決定（2026-08-22）**
>
> *既存システムのリバースで性能目標値の定義が残っていないため、**目標値は立てず、現行システムの実測値を基準に「現行同等」を合格基準とする**。
> このため「目標値(秒)」列は記載できない（＝立てない）ので、**ハイフン `-` を入れて「入力不可」であることを明記**する（空欄で放置しない）。
> 現行実測値と測定条件（件数・測定日）は合格ライン・備考側に残す。書き方は次節を参照。*

*※ 参考：当初は下記A/B/Cから選ぶ任意扱いだったが、本プロジェクトはBで確定した。*

| レベル | 内容 | こういう場合に |
| ------ | ---- | -------------- |
| A：目標値を定義 | 目標値・合格ラインを記載（全注様式のフル形式） | 性能要件が明確／新規に定義できる |
| **B：現行実測を基準（本PJ採用）** | 目標値は立てず、**現行システムの実測値**を記録し「現行同等」を合格基準とする | 目標値は無いが劣化していないことは保証したい |
| C：対象外 | 本ドキュメントは作成しない。その旨と理由を残す | 材料が無く、性能の取り決め自体を行わない |

## 3. 書き方（本PJ＝レベルB）

| 節 | 書くこと |
| -- | -------- |
| 基準値 | レスポンスはデータ量に依存するため、**データ量・テーブル数を加味した**合格値とする（件数の前提なしに「3秒以内」だけ書くと破綻する）。**本PJはレベルBのため「目標値(秒)」列はハイフン `-`（入力不可）**とし、合格ライン(秒)に現行実測を基準とした合格値（現行同等＝実測値、または実測値の1.5倍）を記入、現行実測値・測定条件（件数・測定日）は備考に残す |
| 画面別レスポンス | 画面IDは [システム機能一覧の表B](<../6-1_システム機能一覧/[Sample]6-1_システム機能一覧.md>) と一致させる |
| 前提とするテーブル件数 | テーブルIDは [DB一覧](<../6-7_DB一覧/[Template]6-7_DB一覧.md>) と一致させ、想定件数はDB一覧の「最大レコード件数」と矛盾しないこと |
