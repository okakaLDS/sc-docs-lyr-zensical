# IF一覧 — 使い方

*記入用の様式は [空テンプレート](<[Template]6-6_IF一覧.md>)、記入例は [サンプル](<[Sample]6-6_IF一覧.md>) を参照。*

## 1. 参考様式

*全注（全注文システム）基本設計書 `Ⅴ-5.IF一覧.xlsx` の構成に合わせている。
見出し番号・表の列は全注の実ファイルのものを踏襲している。本システムで不要な列は削ってよい。*

## 2. システム関連図（5-1）との役割分担

| ドキュメント | 単位 | 持つ情報 |
| ------------ | ---- | -------- |
| 5-1 システム関連図 | **1行＝1システム** | 連携の全体像（図）、連携区分（既存／新規・変更／マニュアル）、**連携対象外としたシステム（正）** |
| 6-5 IF一覧（本書） | **1行＝1インターフェース（データ）** | データ形式・連携手段・間隔などの詳細（**正**） |

*同じ情報を両方に書かない。システムを追加したら5-1へ、そのシステムとやり取りするデータを追加したら本書へ1行ずつ足す。*

## 3. 記載のルール

| No. | 項目 | ルール |
| --- | ---- | ------ |
| 1 | 単位 | **1行＝1インターフェース**。同じシステムと複数のデータをやり取りする場合は行を分ける（全注の原本は1セルに複数ファイルをカンマ区切りで書いていたが、検索・抽出できないため分ける） |
| 2 | データ形式と連携手段 | **別の列に分ける**（全注の原本は1セル2段書き） |
| 3 | 方向 | 本システムから見た向きで書く |
| 4 | ファイルとの対応 | ファイル連携の場合、ファイルIDは [ファイル一覧](<../6-5_ファイル一覧/[Template]6-5_ファイル一覧.md>) と一致させる。DB参照・画面遷移などファイルを介さない連携は `-` |
| 5 | 連携方法の特記 | 手運用・他システム経由など、注意が要る事情は「連携方法・備考」に文章で書く |

## 4. 凡例

| 列 | 値の例 | 意味 |
| -- | ------ | ---- |
| 方向 | `発信` / `着信` | 本システムから送る＝発信、受け取る＝着信 |
| データ形式 | `可変長テキスト` / `固定長` / `DB参照` | 連携するデータの形 |
| 連携手段 | `FTP` / `WEBアップロード` / `DB直接参照` / `手運用` | データの受け渡し方法 |
| 連携間隔 | `日次` / `月次` / `随時` / `リアルタイム` | 連携が発生するタイミング |

## 5. 補足

*送信元／送信先のサーバー名は、機器構成が確定してから
[機器構成一覧](<../../10-インフラ設計/10-2_機器構成一覧/[Template]10-2_機器構成一覧.md>) のホスト名で追記する
（全注の原本にも列はあったが全行 `-` だった。確定するまで列を設けない）。*

*「連携対象外としたシステム」は [システム関連図の節5](<../../05-システム設計書（全体）/5-1_システム関連図/[Template]5-1_システム関連図.md>) を正とし、
本書には転記しない（二重管理を避けるため）。*
