## 1. 採番一覧

## 2. 見込No.の採番

### 2-1. 採番方針

| No. | 方針 | 理由 |
| --- | ---- | ---- |
| ① | 日付単位の採番とし、手動採番用の連番桁を設ける | BCPの観点より、システム障害時に手動採番を可能とするため |
| ② | 一意となるよう採番する | 他システムとの連携キーとなるため |

### 2-2. 採番体系

**構成式**

```
見込No.(投入) ＝ 固定①(2桁) + システム日付(yyMMdd) + 連番①(3桁) + 連番②(2桁)
```

**桁内訳**

| パート | 桁数 | 値・範囲 | リセット単位 | 説明 |
| ------ | ---- | -------- | ------------ | ---- |
| 固定① | 2 | 00 / 99 / AA〜ZZ | - | 節2-3参照 |
| システム日付 | 6 | yyMMdd | - | 採番日 |
| 連番① | 3 | 001〜999 | 日次 | システム採番 |
| 連番② | 2 | 01〜99 | 日次 | 手動採番用の枠 |

### 2-3. 固定値・区分値

| 記号・区分 | 値 | 意味 | 採番マスター識別コード |
| ---------- | -- | ---- | ---------------------- |
| 固定① | "00" | 公開/投入時に付与 | "120" |
| 固定① | "99" | 公開/投入前（ドラフト保存時）に付与 | "110" |
| 固定① | AA〜ZZ | 手動採番枠（システム採番では使用しない） | - |

### 2-4. 桁数の妥当性

| 項目 | 値 |
| ---- | -- |
| 想定件数 | 10,000件/月（約500件/営業日） |
| 採番容量 | 連番①が3桁・日次リセットのため 999件/日 |
| 判定 | ピーク日でも枯渇しない。枯渇時は連番②の枠を使用 |

### 2-5. 手動採番・例外

- システム障害時は固定①にアルファベット枠（AA〜ZZ）を用いて手動採番する。
- 基幹システムから連携されたデータが既存採番と紐づかない場合は、グルーピング採番ルールに従う。
