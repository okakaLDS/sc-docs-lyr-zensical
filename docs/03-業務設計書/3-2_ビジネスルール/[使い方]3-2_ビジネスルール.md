# ビジネスルール — 使い方

*記入用の様式は [空テンプレート](<[Template]3-2_ビジネスルール.md>)、記入例は [サンプル](<[Sample]3-2_ビジネスルール.md>) を参照。*

## 1. 参考様式

*全注（全注文システム）基本設計書 `Ⅱ-2.ﾋﾞｼﾞﾈｽﾙｰﾙ.xlsx` の構成に合わせている。
見出し番号・表の列は全注の実ファイルのものを踏襲している。本システムで不要な列は削ってよい。*

*ただし全注が本ドキュメント内に持っている「用語解説」は、
[用語集](<../3-3_用語集/[Template]3-3_用語集.md>)（Ⅱ-3）として別ドキュメントに外出ししている。*

## 2. 各節に書くこと

| 節 | 書くこと |
| -- | -------- |
| 1. システム化範囲 | どこからどこまでをシステム化の対象とするかを記述し、図（`flowchart`）で範囲を示す |
| 2. 業務ルール | 業務上キーとなる概念の扱いをルールとして定義する。**ルール1件＝1セクション**（`### 2-1.` `### 2-2.` …）。本文中の用語は [用語集](<../3-3_用語集/[Template]3-3_用語集.md>) に登録し、初出やわかりにくいものは名指しでリンクする（例：`[見込No.](<../3-3_用語集/[Template]3-3_用語集.md>)`） |
