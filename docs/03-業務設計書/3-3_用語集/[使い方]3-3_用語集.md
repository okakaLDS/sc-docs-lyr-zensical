# 用語集 — 使い方

*記入用の様式は [空テンプレート](<[Template]3-3_用語集.md>)、記入例は [サンプル](<[Sample]3-3_用語集.md>) を参照。*

## 1. このページの位置づけ

*全注（全注文システム）では、用語解説は `Ⅱ-2.ﾋﾞｼﾞﾈｽﾙｰﾙ.xlsx` の中に1セクションとして置かれているが、
本サイトでは**独立したドキュメント（Ⅱ-3）として外出し**している。
用語は業務設計書だけでなく他章からも参照されるため、1か所に集約したほうが追いやすいという判断。*

## 2. 各節に書くこと

| 節 | 書くこと |
| -- | -------- |
| 1. 用語一覧 | 五十音／アルファベット順に並べる。**1用語＝1行** |
| 2. 補足が必要な用語 | 一覧の1行で説明しきれない用語は、ここに見出しを立てて詳しく書く。見出しはリンクの飛び先（アンカー）になるため、他ドキュメントから `[用語名](<[Template]3-3_用語集.md>)` の形で名指しで飛べる |
| 3. 略称・システム名 | 本プロジェクトで登場するシステム・組織の略称をまとめる |

## 3. アンカー名の決まり

> **📌 アンカー名の決まり方**
>
> *見出しから自動生成されるアンカー名は、VSCodeのプレビューとmkdocsで一致するように
> `mkdocs.yml` の `toc.slugify` を設定済み（2026-08-09）。
> 記号は落ち、スペースは `-` になる。例：`### 見込No.（投入）` → `#見込no投入`。
> 迷ったら、ビルド後のHTMLか、VSCodeプレビューで見出しにカーソルを当てて確認する。*
