# 運用方針 — 使い方

*記入用の様式は [空テンプレート](<[Template]9-1_運用方針.md>)、記入例は [サンプル](<[Sample]9-1_運用方針.md>) を参照。*

## 1. 参考様式

*全注（全注文システム）基本設計書 `Ⅷ-1.運用方針.xlsx` の構成に合わせています（原本は11の大項目で構成）。*

> **📌 記入にあたって**
>
> - *[サンプル](<[Sample]9-1_運用方針.md>) の値は全注の実記載を転記したもの。分量の目安・書きぶりの参考に（1〜2文で足りる項目がほとんど）。*
> - *該当しない観点も空欄にせず**「無し」と書く**。可能なら理由を添える（例：「無し（社内イントラネット内でのみ使用する為）」。理由があれば環境変化時に見直すべき項目と分かる）。*
> - *既存環境の共通基盤に乗る項目は「既存サーバーに準拠。」でよい（監視系の例）。*

## 2. 各観点に書くこと

| 観点 | 書くこと |
| ---- | ---- |
| 耐障害性（データ） | バックアップ方式（頻度・方法・DB取得方法）。データ整理・保持は**システム系ファイル（DBダンプ・ログ）のみ**扱い、業務データは [ファイル一覧](<../../06-システム設計書（一覧、管理台帳）/6-5_ファイル一覧/[Template]6-5_ファイル一覧.md>)、テーブルは [DB一覧](<../../06-システム設計書（一覧、管理台帳）/6-7_DB一覧/[Template]6-7_DB一覧.md>) が正（二重管理を避ける） |
| 復旧性 | 代替運用の想定、復旧目標（どの時点まで戻すか） |
| 通常運用 | 運用時間、バックアップ運用（世代管理など） |
| 自動運用 | 自動化する処理、業務スケジュール（実行時刻・順序は [タイムチャート](<../9-2_タイムチャート/[Template]9-2_タイムチャート.md>) が正）、エラー通知・ログ設計 |
| 手動運用 | 手動で行う作業 |
| 運用監視 | システム／サーバー／ストレージ／ネットワークの監視レベル |
| 保守運用 | ソフトウェア配布（サーバー／端末の更新方式） |
| 運用環境 | リモートオペレーション、外部システム接続（接続先は [システム関連図](<../../05-システム設計書（全体）/5-1_システム関連図/[Template]5-1_システム関連図.md>) が正） |
| アクセス・利用制限 | 認証、利用制限（権限は [ユーザーグループ（権限）一覧](<../../05-システム設計書（全体）/5-8_ユーザーグループ（権限）一覧/[Template]5-8_ユーザーグループ（権限）一覧.md>) が正）、管理方法 |
| データの秘匿 | 伝送／蓄積データの暗号化・鍵管理 |
| システム開発方針（運用関連機能） | お知らせ・カレンダー・ログ・通知など、方針と有無のみ（実装詳細は各機能設計書） |
| 運用体制 | 障害時に誰へ連絡するか（本サイト独自の追加。不要なら削除可） |
