# 運用方針 — サンプル（記入例）

*記入イメージの例（全注の実記載を転記）であり、本システムの実データではない。
空テンプレートは [空テンプレート](<[Template]9-1_運用方針.md>)、各観点の趣旨は [使い方](<[使い方]9-1_運用方針.md>) を参照。*

## 1. 耐障害性（データ）

| 項目 | 方針 |
| ---- | ---- |
| バックアップ 取得頻度 | 日次（夜間バッチで実行） |
| バックアップ 取得方法 | 各AP・DBサーバーのデータをバックアップサーバーに集約（robocopyで同期） |
| DBの取得方法 | バックアップ処理でダンプを取得し、そのディレクトリーもコピーしてリモートバックアップを取得 |
| データ整理・保持（システム系のみ） | DBダンプ7日／各種ログ30日（詳細はディレクトリー構成表。業務データは 6.5 ファイル一覧、DBは 6.7 DB一覧が正） |

## 2. 復旧性

| 項目 | 方針 |
| ---- | ---- |
| 代替運用の想定 | 無し |
| 復旧目標 | バックアップ取得時点（＝前日朝の状態）まで切り戻す |

## 3〜4. 通常運用・自動運用（抜粋）

| 項目 | 方針 |
| ---- | ---- |
| 運用時間 | 京セラ本社稼働日の 8:45〜17:30 |
| 自動運用 | DBバックアップ作成・データファイル整理・ログ出力を自動運用で行う |
| 業務スケジュール | 実行時刻・順序は [タイムチャート](<../9-2_タイムチャート/[Template]9-2_タイムチャート.md>) を正とする |

## 5〜11. その他観点（抜粋）

| 観点 | 方針 |
| ---- | ---- |
| 運用監視 | 既存サーバーに準拠。 |
| 外部システム接続 | SC営業支援システム・納期管理システム（連携スキーマ）と接続（接続先の正は [システム関連図](<../../05-システム設計書（全体）/5-1_システム関連図/[Template]5-1_システム関連図.md>)） |
| 利用制限 | ログイン認証時のユーザー権限でメニューの表示/非表示を決定（権限の正は [ユーザーグループ（権限）一覧](<../../05-システム設計書（全体）/5-8_ユーザーグループ（権限）一覧/[Template]5-8_ユーザーグループ（権限）一覧.md>)） |
| データの秘匿 | 無し（社内イントラネット内でのみ使用する為） |
