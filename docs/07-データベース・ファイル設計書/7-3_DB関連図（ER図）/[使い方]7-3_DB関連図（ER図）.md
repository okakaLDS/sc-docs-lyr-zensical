# DB関連図（ER図） — 使い方

*記入用の様式は [空テンプレート](<[Template]7-3_DB関連図（ER図）.md>)、記入例は [サンプル](<[Sample]7-3_DB関連図（ER図）.md>) を参照。*

## 1. 参考様式

*全注（全注文システム）基本設計書 `Ⅵ-3.DB関連図(ER図).xlsx` の構成に合わせている。*

## 2. 記載のルール

| No. | 項目 | ルール |
| --- | ---- | ------ |
| 1 | 正となる情報 | **リレーション一覧を正**とする。図は俯瞰用で、一覧と食い違ったら一覧が正 |
| 2 | 図の分割 | 全テーブルを1枚に描かない。**業務領域ごとに図を分ける**（全注は85超テーブルで1枚は読めない）。1枚あたり10テーブル程度を目安 |
| 3 | 図に載せる項目 | 各テーブルには**キー項目（PK／FK）だけ**を書く。全項目は [DBレイアウト](<../7-1_DBレイアウト/[Template]{テーブルID}_{テーブル名}.md>) が正であり、図に転記しない（二重管理を避ける） |
| 4 | テーブルIDの整合 | [DB一覧](<../../06-システム設計書（一覧、管理台帳）/6-7_DB一覧/[Template]6-7_DB一覧.md>) と一致させる。図・一覧に登場するテーブルは必ずDB一覧に行があること |
| 5 | 複合キーの記法 | Mermaidの複合キーは `PK, FK` と書く（`PK_FK` は構文エラー） |
| 6 | 元データがある場合 | ER図作成ツール（A5:SQL Mk-2 等）の元ファイルやDDLが入手できる場合は、そこから機械的に変換する（手描きで再作成しない） |

## 3. 各節の書き方

| 節 | 書くこと |
| -- | -------- |
| ER図（業務領域別） | 業務領域ごとに小節を分け、`erDiagram` でキー項目のみ記述 |
| リレーション一覧 | リレーションの正。1行＝1リレーション。図に描いていない関連（FK制約を張っていない論理上の関連含む）も漏れなく載せ、論理のみの場合は備考に明記 |
