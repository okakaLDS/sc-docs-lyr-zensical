# ファイルレイアウト — 使い方

*空テンプレートは [Template]{ファイルID}_{ファイル名}、記入例は [サンプル](<[Sample]7-2_ファイルレイアウト.md>) を参照。*

## 1. 参考様式

*全注（全注文システム）基本設計書 `Ⅵ-2.ﾌｧｲﾙﾚｲｱｳﾄ/`（1ファイル＝1Excelファイル）の構成に合わせている。索引は [index](<[Template]{ファイルID}_{ファイル名}.md>)。*

## 2. 記載のルール

| No. | 項目 | ルール |
| --- | ---- | ------ |
| 1 | 単位 | **1ファイル＝1レイアウト定義**。`{ファイルID}_{ファイル名}.md` として作成する |
| 2 | 追加のしかた | `[Template]{ファイルID}_{ファイル名}.md` を複製し、ファイル名を実際の値に置き換える |
| 3 | 対象ファイルの一覧 | [ファイル一覧](<../../06-システム設計書（一覧、管理台帳）/6-5_ファイル一覧/[Template]6-5_ファイル一覧.md>) を正とする。追加したらファイル一覧の「レイアウト」列からリンクする |
| 4 | 同一レイアウトの使い回し | 別ファイルIDが同じレイアウトを使う場合、**レイアウト定義は作らない**。ファイル一覧側の補足に「レイアウトは `FXXX001` と同一」と書き、既存ページへリンクする |
| 5 | 用途列 | 同じレイアウトを複数処理で使い回す場合（一括登録／一括更新など）、項目ごとの使用有無を「用途」列で示す。使用しない項目は理由を書く |
| 6 | 編集仕様 | 桁あふれ・端数処理などの共通ルールは [標準設計書 記述ルール「ファイル出力の書き方」](<../../05-システム設計書（全体）/5-9_標準設計書/5-9-1_記述ルール/[Sample]5-9-1_記述ルール.md>) に従い、本ファイル固有の編集のみ各ページに書く |
| 7 | 索引の更新 | ファイルを追加したら index の一覧に1行足す |

## 3. 形式別の書き方

*まず**ファイル形式**を「ファイル情報」で宣言し、形式に応じて表し方を切り替える。*

| 形式 | 表し方 |
| ---- | ---- |
| 区切り型（TSV/CSV） | 項目レイアウト表（No./項目名/属性/桁数…）。開始位置・バイト数・埋め方は不要 |
| 固定長・バイナリ（`.dat` 等） | 項目レイアウト表に**開始位置・バイト数・埋め方（左詰/右詰・空白/0埋め）**を加える。位置で項目を切り出せるようにする |
| SQL（`.sql`、データをINSERT等で出力） | 項目表の代わりに**「SQL出力仕様」**（対象テーブル・文の種類・カラム⇔項目のマッピング・**サンプルSQL**・終端/文字コード）で表す |

> **📌 DDL・プロシージャーなど「処理」のSQLは本書では扱わない**
>
> *データ出力ではないSQL（CREATE等のDDL、ストアドプロシージャー実行など）は「ファイルのレイアウト」ではなく処理仕様。
> [DB(SQL)処理定義書（8.3）](<../../08-システム機能設計書/8-3_DB(SQL)処理定義書/[使い方]DB(SQL)処理定義書.md>) 側に書く。
> 本書（ファイル一覧・レイアウト）には「SQLスクリプト（レイアウト対象外）」として登録し、詳細は8.3へリンクする。*

*どの形式でも、[サンプル](<[Sample]7-2_ファイルレイアウト.md>) のように**実物1件**を必ず載せる（AI影響調査で形式を正しく解釈させるため）。*
