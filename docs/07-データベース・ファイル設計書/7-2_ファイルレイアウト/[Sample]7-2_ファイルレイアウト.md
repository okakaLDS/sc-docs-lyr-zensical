# ファイルレイアウト（サンプル）— 形式別の記入例

*記入イメージの例であり、実データではない。空テンプレートは [Template]{ファイルID}_{ファイル名}、書き方は [使い方](<[使い方]7-2_ファイルレイアウト.md>) を参照。
実ファイルは**1ファイル＝1ページ**で作る。ここでは形式ごとの書き方が分かるよう、3例を1ページにまとめている。*

---

## 例A：区切り型（TSV）

### A-1. ファイル情報

| 項目 | 内容 |
| ---- | ---- |
| ファイルID | `FAZS121` |
| ファイル名 | 注文一括取込データ |
| 物理ファイル名 | `FAZS121_yyyyMMddhhmmssSSS.tsv` |
| ファイル形式 | TSV |
| 文字コード | UTF-8 |
| 改行コード | CRLF |
| ヘッダー行の有無 | あり |
| 作成者 / 作成日 | 岡 / 2026-04-01 |

### A-2. ファイルレイアウト

*区切り型のため、開始位置・バイト数・埋め方は使わない（列を削除）。*

| No. | 項目名 | 項目ID | 属性 | 桁数 | 有効桁数 | 必須 | default | 用途 | 備考 |
| --- | ------ | ------ | ---- | ---- | -------- | ---- | ------- | ---- | ---- |
| 1 | 注文番号 | OrderNo | 文字 | 20 | 20 | ● | | 一括登録／一括更新で使用 | |
| 2 | 品目コード | ItemCD | 文字 | 20 | 20 | ● | | 一括登録／一括更新で使用 | |
| 3 | 数量 | Qty | 数値 | 10 | 10 | ● | 0 | 一括登録のみで使用 | |

**実物サンプル（先頭2行）**

```text
OrderNo	ItemCD	Qty
0000000000000012345	ABC-100	10
```

### A-3. 編集仕様

| No. | 項目 | 固有の編集内容 |
| --- | ---- | -------------- |
| 1 | 数量 | 小数は切り捨て、整数部のみ出力 |

## 例B：固定長（.dat）

### B-1. ファイル情報

| 項目 | 内容 |
| ---- | ---- |
| ファイルID | `FAZS210` |
| ファイル名 | 会計連携データ |
| 物理ファイル名 | `FAZS210_yyyyMMdd.dat` |
| ファイル形式 | 固定長 |
| 文字コード | Shift_JIS |
| 改行コード | CRLF（1レコード＝50バイト＋改行） |
| ヘッダー行の有無 | なし |
| 作成者 / 作成日 | 岡 / 2026-04-01 |

### B-2. ファイルレイアウト

*固定長のため、開始位置・バイト数・埋め方で各項目を切り出す（1始まり・バイト単位）。*

| No. | 項目名 | 項目ID | 属性 | 開始位置 | バイト数 | 埋め方 | 必須 | 用途 | 備考 |
| --- | ------ | ------ | ---- | -------- | -------- | ------ | ---- | ---- | ---- |
| 1 | 伝票番号 | SlipNo | 文字 | 1 | 10 | 左詰・空白埋め | ● | 会計連携で使用 | |
| 2 | 勘定科目コード | AcctCD | 文字 | 11 | 6 | 左詰・空白埋め | ● | 会計連携で使用 | |
| 3 | 金額 | Amount | 数値 | 17 | 12 | 右詰・0埋め | ● | 会計連携で使用 | 符号なし・円単位 |
| 4 | 計上日 | PostDate | 日付 | 29 | 8 | ―（YYYYMMDD） | ● | 会計連携で使用 | |
| 5 | 予備 | Filler | 文字 | 37 | 14 | 空白埋め | | 使用しない※ | 桁合わせ用の予備領域 |

*※「使用しない」項目が存在する場合は理由を書く（本例は将来拡張用の予備領域）。*

**実物サンプル（1レコード＝50バイト。`_` は空白、`|` は目視用の桁境界で実データには含まれない）**

```text
SL00012345|ABC001|000000150000|20260401|______________
```

### B-3. 編集仕様

| No. | 項目 | 固有の編集内容 |
| --- | ---- | -------------- |
| 1 | 金額 | 円未満は切り捨て。マイナス値は発生しない前提 |

## 例C：SQL出力（.sql、データをINSERTで出力）

*データをSQL文で書き出す例。CREATE等のDDL・プロシージャーは本書では扱わず、[DB(SQL)処理定義書（8.3）](<../../08-システム機能設計書/8-3_DB(SQL)処理定義書/[使い方]DB(SQL)処理定義書.md>) に書く。*

### C-1. ファイル情報

| 項目 | 内容 |
| ---- | ---- |
| ファイルID | `FAZS330` |
| ファイル名 | マスター移行データ |
| 物理ファイル名 | `FAZS330_yyyyMMdd.sql` |
| ファイル形式 | SQL |
| 文字コード | UTF-8 |
| 改行コード | LF |
| ヘッダー行の有無 | ―（SQLスクリプト） |
| 作成者 / 作成日 | 岡 / 2026-04-01 |

### C-2. SQL出力仕様

| 項目 | 内容 |
| ---- | ---- |
| 対象テーブル | `M_ITEM`（品目マスター） |
| 文の種類 | INSERT |
| 1文の単位 | 1レコード＝1文 |
| 文の終端・区切り | 各文末に `;` |
| 文字コード / 改行 | UTF-8 / LF |
| トランザクション | 全体を1トランザクション（末尾に `COMMIT;`） |

**カラム⇔元データ項目のマッピング**

| SQLのカラム | 元データ項目 | 属性 | 備考 |
| ----------- | ------------ | ---- | ---- |
| `ITEM_CD` | 品目コード | 文字(20) | 主キー |
| `ITEM_NAME` | 品目名 | 文字(40) | |
| `UNIT_PRICE` | 単価 | 数値(10) | 円単位 |

**サンプルSQL（実際に出力される例）**

```sql
INSERT INTO M_ITEM (ITEM_CD, ITEM_NAME, UNIT_PRICE) VALUES ('ABC-100', '部品A', 1500);
INSERT INTO M_ITEM (ITEM_CD, ITEM_NAME, UNIT_PRICE) VALUES ('ABC-200', '部品B', 3200);
COMMIT;
```

### C-3. 編集仕様

| No. | 項目 | 固有の編集内容 |
| --- | ---- | -------------- |
| 1 | 品目名 | 値中の `'`（単一引用符）は `''` にエスケープする |
