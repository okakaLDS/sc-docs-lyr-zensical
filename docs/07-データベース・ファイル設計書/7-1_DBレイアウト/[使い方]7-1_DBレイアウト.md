# DBレイアウト — 使い方

*空テンプレートは [Template]{テーブルID}_{テーブル名}、記入例は [サンプル](<[Sample]7-1_DBレイアウト.md>) を参照。*

## 1. 参考様式

*全注（全注文システム）基本設計書 `Ⅵ-1.DBﾚｲｱｳﾄ/`（1テーブル＝1Excelファイル、69ファイル）の構成に合わせている。
索引は [index](<[Template]{テーブルID}_{テーブル名}.md>)。*

## 2. 記載のルール

| No. | 項目 | ルール |
| --- | ---- | ------ |
| 1 | 単位 | **1テーブル＝1ファイル**。`{テーブルID}_{テーブル名}.md` として作成する |
| 2 | 追加のしかた | `[Template]{テーブルID}_{テーブル名}.md` を複製し、ファイル名を実際の値に置き換える |
| 3 | 対象テーブルの一覧 | [DB一覧](<../../06-システム設計書（一覧、管理台帳）/6-7_DB一覧/[Template]6-7_DB一覧.md>) を正とする。追加したらDB一覧の「レイアウト」列からリンクする |
| 4 | 共通システム項目 | フレームワーク標準の項目（No.1〜6）は**全テーブルに必ず存在する**。各ファイルにも省略せず記載する（1ファイルだけ読んでも全カラムが分かるように） |
| 5 | 索引の更新 | ファイルを追加したら index の一覧に1行足す |

## 3. 凡例

| 列 | 意味 |
| -- | ---- |
| PK | 主キー。複合キーの場合は順序を数字で示す（1, 2, …） |
| UK | ユニークキー。複合の場合は順序を数字で示す |
| X1〜X5 | インデックス。同じ番号の列が1つのインデックスを構成する。使う数だけ列を増やす |
| default | 既定値 |
| notnull | `Y` でNOT NULL制約あり |
| タイムゾーン | タイムゾーン付き日時型の場合に記載 |

*キー項目の変更（PKの追加・変更）は影響が大きいため、変更時は
`08-システム機能設計書/` 配下の更新条件表・検索条件表の整合も必ず確認すること。*
