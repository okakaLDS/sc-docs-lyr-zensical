# 設計書構成

機能: S032A 積送日数マスタ

## 1. 機能概要

| 項目            | 内容                                                                                                                                                                                                 |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 機能ID          | S032A                                                                                                                                                                                                |
| 機能名          | 積送日数マスタ                                                                                                                                                                                       |
| 概要            | 積送日数マスタ（`SEKISOU_NISSUU_MST`）を、事業所CD／取引先CD／送付先CD／AT区分をキーとして検索・一覧表示し、明細行の「日数」をインライン編集で更新する。1件ずつの追加（ポップアップ）、Excelファイルによる一括取込（アップロード）、選択行の削除、一覧のExcel出力（ダウンロード）を行う。 |
| 作成者 / 作成日 | 不明（原設計書未受領のため未特定）                                                                                                                                                                   |
| 更新者 / 更新日 | Rikkei / 2026-09-10                                                                                                                                                                                  |
