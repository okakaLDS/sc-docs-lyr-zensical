```text
　→ WHEN MATCHED THEN UPDATE ／ WHEN NOT MATCHED THEN INSERT
```

### 特記事項

- **MERGEのINSERT側は`UPDATED_*`3列を`NULL`で登録する**（No.9〜11）。そのため新規登録直後の行は
  `UPDATED_DATE`が`NULL`となり、一覧の非表示項目`up<行番号>`も空文字となる。
  「更新」ボタン押下時の排他チェックは空文字同士の比較で一致するため、正常に更新できる。
- **INSERT時に監査列へ設定するプログラム名は`CREATED_PRG_NM`のみ**で、`UPDATED_PRG_NM`は
  INSERT時もUPDATE時も設定されない（常に`NULL`のまま）。現状のコード上の事実として記録する。
- **`NISSUU`は`String`のままバインドされる**（`setString(5, data.getNISSUU(), stmt)`）。
  カラム型は`NUMBER(3, 0)`のため、Oracleの暗黙型変換に依存している。
  画面側のJSチェックは2桁までしか許容しないため、3桁の値は画面経由では登録できない
  （[チェック処理概要](M32_02_チェック処理概要.md)【日数の値変更時】No.2参照）。
