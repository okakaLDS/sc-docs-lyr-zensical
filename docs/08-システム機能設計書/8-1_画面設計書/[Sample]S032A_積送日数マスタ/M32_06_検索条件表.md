## 契機×検索 対応表

**検索条件表は契機（ボタン）単位ではなく検索単位で作成し、契機との対応は本表で管理する。**

| 契機（ボタン・イベント）                     | 起動する検索条件表No. | 備考                                                                                     |
| -------------------------------------------- | --------------------- | ---------------------------------------------------------------------------------------- |
| 初期表示                                     | 該当なし              | 一覧は表示せず、検索は行わない                                                           |
| 検索ボタン押下（検索条件を1つ以上入力）      | No.1                  | `onClickselect`→`select`                                                                 |
| 検索ボタン押下（検索条件4項目すべて未入力）  | No.2                  | `onClickselect`→`all_select`（全件検索）                                                 |
| 更新ボタン押下                               | No.1                  | 排他チェックのため対象行のキーで再検索する（`control_eventHandller("select")`）           |
| 削除ボタン押下                               | No.1／No.2            | 削除実行後の再検索（`onClickselect`を再呼び出し）                                        |
| アップロードボタン押下                       | No.1／No.2            | 取込完了後の再検索（同上）                                                               |
| ダウンロードボタン押下                       | 該当なし              | 新規SQLを発行せず、直前の検索結果セットを再利用する（[帳票設計書](M32_03_帳票設計書_01.md)参照） |

## 検索条件表 No.1

| 項目 | 内容                                                                              |
| ---- | --------------------------------------------------------------------------------- |
| 概要 | 画面入力された検索条件で積送日数マスタを取得する（動的SQL）。                      |
| 用途 | 検索ボタン押下時（検索条件を1つ以上入力した場合）：一覧に表示するマスター情報の取得 |

### 検索条件

| 検索条件（テーブル別名）             | 演算子 | 条件項目名（参照先） | 結合条件 | スペース  | 必須   | 備考                                                                 |
| ------------------------------------ | ------ | -------------------- | -------- | --------- | ------ | -------------------------------------------------------------------- |
| `SEKISOU_NISSUU_MST.JIGYOSHO_CD`     | =      | M32.事業所CD         | AND      | Delete    | Option | 未入力時は条件から除外（動的SQL）。カンマ区切りで2件以上指定時はIN条件相当 |
| `SEKISOU_NISSUU_MST.TORIHIKISAKI_CD` | =      | M32.取引先CD         | AND      | Delete    | Option | 同上                                                                 |
| `SEKISOU_NISSUU_MST.SOFUSAKI_CD`     | =      | M32.送付先CD         | AND      | Delete    | Option | 同上                                                                 |
| `SEKISOU_NISSUU_MST.AT_KBN`          | =      | M32.AT区分           | －       | Delete    | Option | 同上                                                                 |

*記入方法：*SQL本体のWHERE句はプレースホルダ`$1$`〜`$4$`の4つで構成され、
`prepare()`で未入力項目を判定したうえで`SqlFormat.formatDyncond()`により該当条件を除去する
（`isNull`が1つでも真の場合のみ動的SQL生成を行い、すべて入力済みの場合は元のSQLをそのまま使用する）。

### 結合条件

該当なし（単一テーブル検索のため）。

### 抽出条件

該当なし（固定値による絞り込みは行わない）。

### ソート順（※NULLは末尾）

| No. | 項目名                               | ASC/DESC | 備考                             |
| --- | ------------------------------------ | -------- | -------------------------------- |
| 1   | `SEKISOU_NISSUU_MST.JIGYOSHO_CD`     | ASC      | SQL上は`ORDER BY 1, 2, 3, 4`（列番号指定） |
| 2   | `SEKISOU_NISSUU_MST.TORIHIKISAKI_CD` | ASC      | 同上                             |
| 3   | `SEKISOU_NISSUU_MST.SOFUSAKI_CD`     | ASC      | 同上                             |
| 4   | `SEKISOU_NISSUU_MST.AT_KBN`          | ASC      | 同上                             |

### グループ化

該当なし。

### 取得項目

| No. | 取得項目名                            | 取得できない場合 |
| --- | ------------------------------------- | ---------------- |
| 1   | `SEKISOU_NISSUU_MST.JIGYOSHO_CD`      | －               |
| 2   | `SEKISOU_NISSUU_MST.TORIHIKISAKI_CD`  | －               |
| 3   | `SEKISOU_NISSUU_MST.SOFUSAKI_CD`      | －               |
| 4   | `SEKISOU_NISSUU_MST.AT_KBN`           | －               |
| 5   | `SEKISOU_NISSUU_MST.NISSUU`           | －               |
| 6   | `SEKISOU_NISSUU_MST.UPDATED_DATE`     | －（排他チェック用。画面では非表示項目`up<行番号>`に保持） |

### 取得件数／0件時の扱い

| 項目              | 内容                                                                                                       |
| ----------------- | ---------------------------------------------------------------------------------------------------------- |
| 取得件数          | 複数件                                                                                                     |
| 抽出結果0件の場合 | エラーとせず一覧を空表示のまま処理を継続する（メッセージは表示しない）。「削除」「ダウンロード」ボタンが非活性になる |

## 検索条件表 No.2

| 項目 | 内容                                                                       |
| ---- | -------------------------------------------------------------------------- |
| 概要 | 検索条件を一切指定せず、積送日数マスタを全件取得する。                     |
| 用途 | 検索ボタン押下時（検索条件4項目すべて未入力の場合）：一覧に表示する全件取得 |

### 検索条件

該当なし（WHERE句を持たない固定SQL。No.1とは別のSQL文として`all_select`クラスに定義されている）。

### 結合条件

該当なし（単一テーブル検索のため）。

### 抽出条件

該当なし。

### ソート順（※NULLは末尾）

No.1と同一（`ORDER BY 1, 2, 3, 4`）。

### グループ化

該当なし。

### 取得項目

No.1と同一（`JIGYOSHO_CD`／`TORIHIKISAKI_CD`／`SOFUSAKI_CD`／`AT_KBN`／`NISSUU`／`UPDATED_DATE`）。

### 取得件数／0件時の扱い

| 項目              | 内容                                                     |
| ----------------- | -------------------------------------------------------- |
| 取得件数          | 複数件                                                   |
| 抽出結果0件の場合 | No.1と同一（エラーとせず一覧を空表示のまま処理を継続）   |
