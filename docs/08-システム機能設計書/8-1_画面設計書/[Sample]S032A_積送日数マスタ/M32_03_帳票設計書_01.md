## 1. 帳票出力条件

### 参照エンティティ一覧

| 記号                 | 内容                              |
| -------------------- | --------------------------------- |
| `SEKISOU_NISSUU_MST` | 積送日数マスタ（スキーマ`LYR19`） |
| M32                  | 積送日数マスタ（出力契機の画面）  |

### 抽出条件・検索条件・結合条件

出力対象データは新たにSQLを発行せず、**直前の一覧検索（[検索条件表](M32_06_検索条件表.md)No.1／No.2）で
取得済みの結果セット（セッション上の`blyr07_M32Control`が保持するリスト）を再利用する**。
そのため本帳票固有の検索条件・結合条件は存在しない。

| 検索条件 | 演算子 | 条件項目名 | 結合条件 | スペース | 必須 | 備考                                                       |
| -------- | ------ | ---------- | -------- | -------- | ---- | ---------------------------------------------------------- |
| 該当なし | －     | －         | －       | －       | －   | 一覧検索の結果セットをそのまま出力するため（上記のとおり） |

#### 結合条件（外部結合）

該当なし（単一テーブルの一覧をそのまま出力するため）。

### 出力対象行の選択

`onClickdownload`はチェックされた行番号（`DW_FLG`）を`DL_LIST`としてセッションへ格納する。

**注意（現状のコード上の事実）**：`lyr07_M32DL.jsp`は`DL_LIST`を参照せず、
`blyr07_M32Control.getListsize()`によりセッション上の一覧を**全件ループして出力する**。
したがって行を選択してダウンロードしても、実際には一覧の全件が出力される。
また`onClickdownload`のチェックなし（`str_DW_FLG == null`）時の全件対象化ループは中身が空であり、
`DL_LIST`は空リストのまま格納される。設計変更ではなく現状のコード上の事実として記録する。

## 2. 帳票出力仕様

| 項目                             | 内容                                                                                                    |
| -------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 出力ファイル名（表示ファイル名） | `yyyyMMddHHmmss + "SEKISOU.xls"`（例：`20260910143005SEKISOU.xls`）                                     |
| 出力ファイル名（物理ファイル名） | 同上（クライアントのダウンロード先に保存されるのみで、サーバー側に物理ファイルを生成しない）            |
| 帳票用途                         | 積送日数マスタの登録内容の確認・オフライン編集（編集後は同一画面の「アップロード」で取込可能）          |
| 出力方法                         | EXCEL形式（SpreadsheetML 2003。JSPが直接XMLを書き出す）                                                 |
| 引用符                           | なし（XML形式のため該当しない）                                                                         |
| 出力先                           | クライアント任意のディレクトリー（`Content-Disposition: attachment`）                                     |
| レコード長                       | 該当なし（固定長ではない）                                                                              |
| 文字コード                       | UTF-8（`contentType="application/octet-stream; charset=utf-8"`）                                        |
| 改行コード                       | 該当なし（XML形式のため）                                                                               |
| 0件出力                          | ヘッダー行のみのファイルを出力する（チェックエラーとしない）。ただしM32画面側は一覧0件時に「ダウンロード」ボタンを非活性にするため、通常は0件出力に至らない |
| 備考                             | シート名：`積送日数マスタ一覧表`。ヘッダー行を固定表示（`x:SplitHorizontal=435`／`x:TopRowBottomPane=1`） |

## 3. 編集仕様

全出力項目に共通する編集ルールは特記なし（各項目は`null`の場合に空文字へ変換したうえで、
`ss:Type="String"`としてそのまま出力する。桁数の切り詰め・丸め・書式変換は行わない）。

「日数」列のみセルスタイルに`NumberFormat ss:Format="#,##0"`（右寄せ）を適用するが、
データ型は`String`で出力するため、Excel上では文字列として扱われる（現状のコード上の事実）。

### 項目定義（ヘッダー部／明細部）

| No. | 出力項目名 | 参照先                               | 出力内容        | 桁1 | 桁2 | 出力形式 | 列幅 | セルスタイル   | 備考                             |
| --- | ---------- | ------------------------------------ | --------------- | --- | --- | -------- | ---- | -------------- | -------------------------------- |
| 1   | AT区分     | `SEKISOU_NISSUU_MST.AT_KBN`          | AT区分          | 1   | －  | －       | 80   | `mS1111`       | 中央寄せ                         |
| 2   | 事業所CD   | `SEKISOU_NISSUU_MST.JIGYOSHO_CD`     | 事業所CD        | 3   | －  | －       | 80   | `mS1111`       | 中央寄せ                         |
| 3   | 取引先CD   | `SEKISOU_NISSUU_MST.TORIHIKISAKI_CD` | 取引先CD        | 8   | －  | －       | 150  | `mS1111`       | 中央寄せ                         |
| 4   | 送付先CD   | `SEKISOU_NISSUU_MST.SOFUSAKI_CD`     | 送付先CD        | 22  | －  | －       | 150  | `mS1111`       | 中央寄せ                         |
| 5   | 日数       | `SEKISOU_NISSUU_MST.NISSUU`          | 日数            | 3   | 0   | `#,##0`  | 80   | `mS1111Rnum`   | 右寄せ。`ss:Type="String"`で出力 |

ヘッダー部は上記No.1〜5と同一の列順・同一の項目名（`AT区分`／`事業所CD`／`取引先CD`／`送付先CD`／`日数`）を
文字列として1行目に出力する（セルスタイル`mB1111g`＝太字・背景色`#C0C0C0`）。
この列名はアップロード時のヘッダー判定に使用される列名と一致しているため、
ダウンロードしたファイルを編集して同一画面からアップロードできる。
