## 4. 設計書構成

本機能で作成する**画面単位の設計書（Markdownファイル）を画面ID順**に列挙する。作成したページには
「作成」＋ファイルへのリンクを、作成不要なページには「対象外」＋対応ページ欄に理由を記載する。
本ページ（`index.md`＝表紙・機能概要）は機能単位のページであり、本表には含めない。

画面が2つ以上ある機能では、下記6行を画面ごとに複製し、画面ID順に並べたうえでNo.を1から振り直す。

| No. | 画面ID | 設計書名（KCCS基本） | 作成有無 | 本フォルダーでの対応ページ |

| 2 | （記入。画面ID） | チェック処理概要 | （記入） | `{screen-id}_02_check-process-overview.md` |
