## 1. 画面レイアウト

実機画面キャプチャは未取得。構成は以下の通り（`lyr07_JZ01.jsp`、単一フォーム`form1` → `lyr07_JZ01Servlet`）。

- 上部：検索条件フォーム（13項目＋チェックボックス2項目）。項目は「5. 画面項目定義」の検索条件欄を参照。
- 検索条件の右側：ボタン列（注残検索／検索条件検索／ダウンロード／印刷）。
- 下部：検索結果グリッド（ヘッダー行＋20列）。1行＝1製伝。行の背景色は製伝の状態により変化する（下記「行の状態表示」参照）。
- グリッド上部に選択行番号を保持する非表示要素`POINTER`、累計表示用の`yotei`／`YOTEI_R`要素を持つ。

### 行の状態表示（`dtl()`内の`className`判定）

| クラス名 | 状態                     | 背景色      | 文字色    |
| -------- | ------------------------ | ----------- | --------- |
| `BL`     | 製造回答済・製造見直し済 | `#00ccff`   | `#000000` |
| `GR`     | 営業確認済               | `#99ff00`   | `#000000` |
| `YE`     | 営業見直し               | `#ffff99`   | `#000000` |
| `RE`     | 納期遅れ                 | `#ff0000`   | `#000000` |
| `BK`     | 済み製伝                 | `#000000`   | `#ffffff` |
| `RD`     | 未登録                   | `#ffffff`   | `#ff0000` |
| （空）   | 未回答                   | `#ffffff`   | `#000000` |
| 上記以外 | その他                   | `#333333`   | `#000000` |

## 2. 画面表示制御・表示パターン

| 項目               | 内容                                                                                                                                                                                  |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 初期表示           | `initialEvent`（`controlINITIAL`）はDBアクセスを行わず画面を表示するのみ。`reloadEvent`（`controlRELOAD`）でコンボボックスの選択肢（事業部名／事業所／事業部名称）を生成する。検索ボタン押下まで一覧は表示されない。 |
| 前回検索条件の保存 | **あり（自動保存）。**「注残検索」「ダウンロード」押下時に、入力中の検索条件を`LYR03_DEF_TBL`へユーザー単位で保存する（既存行があればUPDATE、なければINSERT）。詳細は[更新条件表](JZ01_05_更新条件表.md)。 |
| 保存条件の呼び出し | 「検索条件検索」押下時に`LYR03_DEF_TBL`から保存済み条件を読み込む（`controlsearchSelect`は`LIST_DEF`の読み込みのみを行い、一覧検索は行わない）。 |
| データ更新状況の表示 | 検索・ダウンロード時に`UPDATE_FLG`を実行し、連携元データ（`SQLLDR_UPDATE`／`LYR03_EXP_TBL`／`CB52`）の最終更新日時と新旧比較フラグを取得して画面に表示する。 |
