## 契機×検索 対応表

**検索条件表は契機（ボタン）単位ではなく検索単位で作成し、契機との対応は本表で管理する。**

| 契機（ボタン・イベント）   | 起動する検索条件表No. | 備考                                                                          |
| -------------------------- | --------------------- | ----------------------------------------------------------------------------- |
| 初期表示（`controlINITIAL`） | 該当なし              | DBアクセスを行わない                                                          |
| リロード（`controlRELOAD`） | No.5, No.6, No.7      | コンボボックスの選択肢生成。ボタン押下ではない契機                            |
| 注残検索ボタン押下         | No.3, No.1, No.4      | `LIST_DEF`（保存条件読込）→条件保存→`LIST_SEIDEN`（一覧）→`UPDATE_FLG`         |
| 検索条件検索ボタン押下     | No.3                  | `LIST_DEF`のみ。一覧検索は行わない                                            |
| ダウンロードボタン押下     | No.3, No.2, No.4      | `LIST_DEF`→条件保存→`LIST_SEIDEN_dl`（出力用一覧）→`UPDATE_FLG`               |
| 印刷ボタン押下             | 該当なし              | `controlprintpage`はDBアクセスを行わず、直前の検索結果を再利用する            |
| （共通）                   | No.8                  | `ei_Sysdate`によるシステム日時取得。`control_eventHandller`から呼ばれる        |
