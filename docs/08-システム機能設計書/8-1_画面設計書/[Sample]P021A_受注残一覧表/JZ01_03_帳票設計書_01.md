## 1. 帳票出力条件

### 参照エンティティ一覧

| 記号            | 内容                                                  |
| --------------- | ----------------------------------------------------- |
| `JCHZN_TBL`     | 受注残データ（出力の主テーブル）                      |
| `KC_HINMEI_TBL` | KC品名（製伝単位）                                    |
| `KC_HINMEI_MST` | KC品名マスター（図番単位）                            |
| `LYR03_EXP_TBL` | 生産実績（当日分の生産数集計）                        |
| `CB52`          | 生産実績（基幹側）                                    |
| `LYR03_DEF_TBL` | 検索条件保存（出力前に条件を保存する）                |
| JZ01            | 受注残一覧表（出力契機の画面）                        |

### 抽出条件・検索条件・結合条件

本帳票は**画面一覧とは別のSQL（`LIST_SEIDEN_dl`）を新規に発行して出力データを取得する**
（S021Gの帳票のように直前の結果セットを再利用する方式ではない）。検索条件は画面の入力値をそのまま
使用するため、条件・結合条件は[検索条件表](JZ01_06_検索条件表.md)No.2と同一である。

| 検索条件                       | 演算子 | 条件項目名   | 結合条件 | スペース | 必須 | 備考                                                                  |
| ------------------------------ | ------ | ------------ | -------- | -------- | ---- | --------------------------------------------------------------------- |
| [検索条件表](JZ01_06_検索条件表.md)No.2を参照 | －     | －           | －       | －       | －   | 画面一覧用（No.1）と取得項目が異なるだけで、抽出条件は共通            |

#### 結合条件（外部結合）

該当なし（`JCHZN_TBL`を主テーブルとし、他テーブルはスカラー副問合せで参照するため）。

### 出力処理の流れ（`controldwselect`）

| 順 | 処理                    | 内容                                                                   |
| -- | ----------------------- | ---------------------------------------------------------------------- |
| 1  | `LIST_DEF.read`         | `LYR03_DEF_TBL`から当該ユーザーの保存済み検索条件を読み込む            |
| 2  | `DEF_SAVE.create/update` | 画面の検索条件を`LYR03_DEF_TBL`へ保存する（[更新条件表](JZ01_05_更新条件表.md)） |
| 3  | `LIST_SEIDEN_dl.read`   | 出力用の一覧を取得する（[検索条件表](JZ01_06_検索条件表.md)No.2）      |
| 4  | `UPDATE_FLG.read`       | 連携元データの更新状況を取得する（同No.4）                             |
| 5  | 画面遷移                | `/lyr07_JZ01DLL.jsp`へ遷移しExcelを書き出す                            |

## 2. 帳票出力仕様

| 項目                             | 内容                                                                                               |
| -------------------------------- | -------------------------------------------------------------------------------------------------- |
| 出力ファイル名（表示ファイル名） | `"DJZ_" + yyyyMMdd + ".xls"`（例：`DJZ_20260910.xls`）                                             |

| 出力先                           | クライアント任意のディレクトリー（`Content-Disposition: attachment`）                                |
| レコード長                       | 該当なし（固定長ではない）                                                                         |
| 文字コード                       | UTF-8（`contentType="application/octet-stream; charset=utf-8"`）                                   |
| 改行コード                       | 該当なし（XML形式のため）                                                                          |
| 0件出力                          | 【検索条件】ブロックとヘッダー行のみのファイルを出力する（チェックエラーとしない。[チェック処理概要](JZ01_02_チェック処理概要.md)【ダウンロードボタン押下時】参照） |
| 備考                             | ファイル名は時刻を含まないため、同一日に複数回出力するとファイル名が重複する（現状のコード上の事実） |

## 3. 編集仕様

全出力項目に共通する編集ルールは特記なし（各項目は`null`の場合に空文字へ変換して出力する）。
日付項目（最新納期・製伝発行日）はSQL側で`TO_CHAR(TO_DATE(項目,'YYYYMMDD'),'YY/MM/DD')`により
`YY/MM/DD`形式へ変換済みの値を使用する。金額・数量項目はセルスタイルで右寄せ・桁区切りを適用する。
