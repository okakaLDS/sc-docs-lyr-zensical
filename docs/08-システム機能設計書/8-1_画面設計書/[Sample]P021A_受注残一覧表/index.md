# 設計書構成

機能: P021A 受注残一覧表

## 1. 機能概要

| 項目            | 内容                                                                                                                                                                                                                           |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 機能ID          | P021A                                                                                                                                                                                                                          |
| 機能名          | 受注残一覧表                                                                                                                                                                                                                   |
| 概要            | 製造部門向けに、製伝（製造伝票）単位の受注残情報を事業部・事業所・加工部門・取引先等の条件で検索し一覧表示する。検索実行時には入力した検索条件をユーザー単位で自動保存し、次回以降呼び出せる。一覧は印刷用画面での印刷とExcel形式でのダウンロードが可能。明細の製伝No.押下で製伝詳細情報画面（別機能`P001C`／`L01`）を別ウィンドウで開く。 |
| 作成者 / 作成日 | 不明（原設計書未受領のため未特定）                                                                                                                                                                                             |
| 更新者 / 更新日 | Rikkei / 2026-09-10                                                                                                                                                                                                            |

| 更新対象テーブル | `LYR03_DEF_TBL`（検索条件保存）— 詳細は[更新条件表](JZ01_05_更新条件表.md)                              |

## 4. 設計書構成

本機能で作成する**画面単位の設計書（Markdownファイル）を画面ID順**に列挙する。作成したページには
「作成」＋ファイルへのリンクを、作成不要なページには「対象外」＋対応ページ欄に理由を記載する。
本ページ（`index.md`＝表紙・機能概要）は機能単位のページであり、本表には含めない。

| No. | 画面ID | 設計書名（KCCS基本） | 作成有無 | 本フォルダーでの対応ページ |
| --- | ------ | -------------------- | -------- | ------------------------ |
| 1 | JZ01 | 画面設計 | 作成 | [JZ01_01_画面設計.md](JZ01_01_画面設計.md) |
| 2 | JZ01 | チェック処理概要 | 作成 | [JZ01_02_チェック処理概要.md](JZ01_02_チェック処理概要.md) |

| 4 | JZ01 | プレビュー画面設計書 | 作成 | [JZ01_04_プレビュー画面設計書_01.md](JZ01_04_プレビュー画面設計書_01.md)（印刷用画面`JZ01P`の設計。帳票設計書と同じく押下元画面`JZ01`のIDで採番） |
