# 設計書構成

機能: S021G 売上予定管理

## 1. 機能概要

| 項目            | 内容                                     |
| --------------- | ---------------------------------------- |
| 機能ID          | S021G                                    |
| 機能名          | 売上予定管理(国内海外共通)               |
| 概要            | 製伝（製造伝票）単位の売上予定データを国内／海外共通で一覧表示・検索し、明細行の「売上予定日」をインライン編集で更新する。結果はExcel形式でダウンロード可能。1件選択のうえ「台帳検索」を押下すると、国内／海外の区分に応じて製伝詳細情報（台帳）画面（`L11`／`I21D`）へ遷移する。 |
| 作成者 / 作成日 | 不明（原設計書未受領のため未特定）        |
| 更新者 / 更新日 | Rikkei / 2026-09-10                      |

## 4. 設計書構成

本機能で作成する**画面単位の設計書（Markdownファイル）を画面ID順**に列挙する。作成したページには
「作成」＋ファイルへのリンクを、作成不要なページには「対象外」＋対応ページ欄に理由を記載する。
本ページ（`index.md`＝表紙・機能概要）は機能単位のページであり、本表には含めない。
