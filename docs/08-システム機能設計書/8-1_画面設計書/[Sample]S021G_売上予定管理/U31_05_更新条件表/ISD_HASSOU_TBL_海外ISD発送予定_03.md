# 更新条件表：ISD_HASSOU_TBL（海外／ISD 発送予定）

/// tab | 本文


| 項目               | 内容                                      |
| ------------------ | ----------------------------------------- |
| システムID／機能ID | S021G                                     |
| テーブルID         | `ISD_HASSOU_TBL`                          |

| 作成日／作成者     | 不明（原設計書未受領のため未特定）        |

### 更新概要

| 操作No. | 種別   | 契機（トリガー）                                        | 概要                                                     |
| ------- | ------ | ---------------------------------------------------------- | ---------------------------------------------------------- |
| UPDATE① | UPDATE | 「更新」ボタン押下時、変更行のうち `TC_CHK != "TC"` かつ `KOKUNAI_KAIGAI_KBN == "2"`（海外）の行 | 当該行の売上予定日（`URIAGE_YOTEIBI`）を更新する。 |

### 更新条件

```text
■UPDATE①-条件
ISD_HASSOU_TBL.SEIDEN_NO = <行のSEIDEN_NO> AND
ISD_HASSOU_TBL.BUNNOU_NO = <行のBUNNOU_NO（分納No）>
※ 画面グリッドの「売上予定日」セルの表示値がDBロード時の値と異なる行のみ対象（サーブレット側で変更検知）。
```

### 更新項目

| No. | 項目名          | UPDATE①：キー                | UPDATE①：設定内容                          |
| --- | ---------------- | ------------------------------- | --------------------------------------------- |
| 1   | URIAGE_YOTEIBI    | -                               | グリッドで編集後の「売上予定日」（`TO_DATE(?,'RR/MM/DD')`） |
| 2   | SEIDEN_NO         | 行データ                        | 【更新キー】製伝No                            |
| 3   | BUNNOU_NO         | 行データ                        | 【更新キー】分納No                            |
| 4   | 更新日時／更新者／更新プログラム等 | - | フレームワーク共通マクロにより自動設定（詳細はソース未深追い） |
