# 更新条件表：MEMO_TBL（型代／TC案件メモ管理）

| 項目               | 内容                                      |
| ------------------ | ----------------------------------------- |
| システムID／機能ID | S021G                                     |

| 更新テーブル       | 型代（TC）案件メモ管理テーブル            |
| 作成日／作成者     | 不明（原設計書未受領のため未特定）        |

### 更新概要

| 操作No. | 種別   | 契機（トリガー）                                      | 概要                                                   |
| ------- | ------ | ----------------------------------------------------- | -------------------------------------------------------- |
| UPDATE① | UPDATE | 「更新」ボタン押下時、変更行のうち `TC_CHK == "TC"` の行（型代管理対象。国内/海外の判定より優先） | 当該行の売上予定日（`TC_URIAGE`）を更新する。 |

### 更新条件

```text
■UPDATE①-条件
MEMO_TBL.SEIDEN_NO = <行のSEIDEN_NO>
※ このテーブルは分納No（BUNNOU_NO）による絞り込みを行わない（他の2テーブルと異なる点）。
```

### 更新項目

| No. | 項目名     | UPDATE①：キー | UPDATE①：設定内容                          |
| --- | ----------- | ---------------- | --------------------------------------------- |
| 1   | TC_URIAGE    | -                | グリッドで編集後の「売上予定日」（`TO_DATE(?,'RR/MM/DD')`） |
| 2   | SEIDEN_NO    | 行データ         | 【更新キー】製伝No                            |
