## 契機×検索 対応表

1つの契機が複数の検索を起動し、1つの検索が複数の契機から共用されるため、検索条件表は契機単位ではなく
検索単位（No.）で作成し、その対応関係を本表で管理する。

| 契機（ボタン・イベント） | 起動する検索条件表No. | 備考 |
| ------------------------ | --------------------- | ---- |
| 初期表示（`initialEvent`／`reloadEvent` → `controlRELOAD`） | （記入：未作成） | コンボボックスの選択肢生成。`mLIST_JIGYOBU`（事業部）／`mLIST_JIGYOSHO`（事業所）／`mLIST_JIGYO_GRP`（営業G）の3検索。**ボタン押下ではない契機** |
| 検索条件呼出（`controlsearchSelect`） | （記入：未作成） | `mLYR03_DEF_MANAGE`（保存済み検索条件セットの読込） |
| 検索条件保存ボタン押下（`controldefsave`） | （記入：未作成） | 保存前の現行値取得に`mLYR03_DEF_MANAGE`を使用。**上段の検索条件呼出と同一の検索を共用** |
| 検索ボタン押下（`controlselect`） | No.1 ＋（記入：未作成） | **1契機で11検索を実行**。No.1（`mLIST_SEIDEN`／`mLIST_SEIDEN_JISSEKI`）のほか、`mURIAGE_KAIGAI_list`・`mSEIZO_KAITOU_KAIGAI_list`・`mURIAGE_KOKUNAI_list`・`mSEIZO_KAITOU_KOKUNAI_list`・`mYAKUSOKU_NOUKI_list`・`mSEIDEN_NOUKI_list`・`mURIAGE_JISSEKI_NOUKI_list`・`mList_ACL`・`mUPDATE_FLG` |
| 今月売上／来月売上／再来月売上ボタン押下 | 検索ボタン押下と同一 | JSで日付範囲（`START_DAY_U`／`END_DAY_U`）を設定したうえで検索ボタンと同じ送信を行うため、起動される検索は同一 |
| ダウンロードボタン押下（`controldwselect`） | 該当なし | 新規のSQLは発行せず、直前の検索結果を`mergeLists`で再利用する |
| 台帳検索ボタン押下（`controlSeidenselect`） | 該当なし | 選択行の値を用いた画面遷移のみで検索を伴わない |
| 更新ボタン押下（`controlupdate`） | 該当なし | 検索は行わない（[更新条件表](U31_05_更新条件表/index.md)参照） |

本サンプルで詳細化済みの検索条件表は一覧検索（No.1）のみ。上表で「（記入：未作成）」としている検索は
本サンプル未着手であり、本表によって未作成の範囲が識別できる状態としている。

## 検索条件表 No.1（一覧検索・「検索」ボタン押下時）

| 項目 | 内容                                                                             |
| ---- | -------------------------------------------------------------------------------- |
| 概要 | 製伝（製造伝票）の分納明細を軸に、国内／海外・見込／実績の4系統をUNION ALLで結合し、検索条件で絞り込んだ一覧を取得する。 |
| 用途 | 「検索」ボタン押下時：一覧グリッドに表示するデータの取得（`onClickselect`）。「実績見込」チェックのON/OFFで使用エンティティが`LIST_SEIDEN`（見込）／`LIST_SEIDEN_JISSEKI`（実績）に切り替わる。 |

実装は **4分岐のUNION ALL**（国内本体／国内タック／海外本体／海外タック、各枝が`ISD_HASSOU_TBL`／`DSD_HASSOU_TBL`／`MEMO_TBL`のいずれかと結合）。各枝の検索条件（WHERE句）はすべて同一構造の繰り返しであり、`$1$`〜`$32$`の番号付きプレースホルダに`PartialSQLGenerator`がcomma区切り値をLIKE/IN展開して代入する。

### ソート順（※NULLは末尾）

画面の「ソート順1〜3」（`SORTING_NO1`/`2`/`3`、固定12種の項目＋昇順/降順）で指定。**SQLのORDER BYではなく、検索結果取得後にメモリー内で`mergeSort()`により適用**される。12種のソートキーの具体的な項目名一覧は未特定。

### グループ化

該当なし（GROUP BYはなし）。

### 取得項目

一覧グリッド37列（[画面設計](U31_01_画面設計.md)参照）に必要な全カラム（`JCHZN_TBL`、`ISD_HASSOU_TBL`/`DSD_HASSOU_TBL`/`MEMO_TBL`、`LYR03_NOUKI_TBL`から取得）。個別項目としての完全列挙は未転記。グリッド列定義（画面設計）を正とする。
