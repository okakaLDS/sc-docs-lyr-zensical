# 帳票設計書

**1帳票につき本ページを1ファイル作成する。** 本機能が出力する帳票は「売上予定一覧ダウンロード」の1件のみのため、
本ファイル（`_01`）だけを作成している。

## ヘッダー情報

| 項目           | 内容                                |
| -------------- | ----------------------------------- |
| システムID     | AZR（納期管理システム）              |
| 機能ID         | S021G                               |
| 画面ID         | U31（売上予定管理 一覧画面。ダウンロードボタンの押下元） |
| 帳票ID         | U31DL（出力元JSP`lyr07_U31DL.jsp`の実名。KCCS標準の出力管理情報を経由しないため、帳票専用の採番はソース上に存在せず、実ファイル名をそのまま使用） |
| 帳票名         | 売上予定一覧ダウンロード             |
| 出力区分       | 帳票（Excel形式（SpreadsheetML、拡張子`.xls`）でレイアウト情報を持つため「ファイル」ではなく「帳票」に分類） |
| ファイルID     | `URIAGE`（`lyr07_U31DL.jsp`のContent-Dispositionヘッダーに直書きされた出力ファイル名固定部分。実際のファイル名は`<タイムスタンプ>URIAGE.xls`） |
| 出力契機       | 一覧画面の「ダウンロード」ボタン押下時 |
| 作成日／作成者 | 不明（原設計書未受領のため未特定）   |

## 1. 帳票出力条件

### 参照エンティティ一覧

| 記号             | 内容                       |
| ---------------- | -------------------------- |
| `JCHZN_TBL`      | 受注残データ               |
| `ISD_HASSOU_TBL` | 海外（ISD）発送予定        |
| `DSD_HASSOU_TBL` | 国内（DSD）発送予定        |
| `MEMO_TBL`       | 型代（TC）案件メモ管理     |
| `LYR03_NOUKI_TBL`| 納期データ                 |
| U31              | 売上予定管理(国内海外共通) |

### 抽出条件・検索条件・結合条件

出力対象データは新たにSQLを発行せず、直前の一覧検索（[検索条件表](U31_06_検索条件表.md)）で取得済みの結果セットを再利用する（`controldwselect()` 内 `mergeLists(..., dwflag=true)`）。ダウンロード時のみ、一覧では展開していない明細（製伝納期・約束納期の内訳行）を `mergeLists_SeidenNouki` / `mergeLists_YakusokuNouki` で追加マージする。

#### 結合条件（外部結合）

一覧検索と共通（[検索条件表](U31_06_検索条件表.md)参照）。ダウンロード専用の追加結合はない。

## 2. 帳票出力仕様

| 項目                             | 内容                                                                              |
| -------------------------------- | --------------------------------------------------------------------------------- |
| 出力ファイル名（表示ファイル名） | `<yyyy><MM><dd><HH><mm><ss>URIAGE.xls`（例：`20260729143205URIAGE.xls`）          |
| 出力ファイル名（物理ファイル名） | 表示ファイル名と同一（`Content-Disposition` で一括指定、一時ファイルへの保存なし） |
| 帳票用途                         | 売上予定管理の一覧・明細データをExcelでダウンロードし、社内共有・保存するため      |
| 出力方法                         | Excel形式（Excel 2003 XML Spreadsheet／`SpreadsheetML`、拡張子`.xls`） |
| 引用符                           | 該当なし（Excel/XML形式のため）                                                   |
| 出力先                           | ブラウザー経由でクライアントの任意のダウンロード先                                  |
| レコード長                       | 可変（Excel形式のため固定長の概念なし）                                          |
| 文字コード                       | UTF-8（SpreadsheetML自体はXML。画面側JSPはCP932だが出力ファイルは別エンコーディング） |
| 改行コード                       | 該当なし（Excel形式のため）                                                       |
| 0件出力                          | 0件時の特別処理（エラー表示・出力抑止等）なし。 |
| 備考                             | 一覧画面の37列に対し、出力ファイルは59列（価格・ファクター等の追加列を含むスーパーセット）。 |

### ソート順（※NULLは末尾）

| No. | 項目名 | ASC/DESC | 備考 |
| --- | ------ | -------- | ---- |
| 1   | （動的。固定のSQL ORDER BYではない） | 画面依存 | 一覧画面の検索条件欄で選択された`SORTING_NO1`〜`3`（[画面設計](U31_01_画面設計.md)参照）をそのまま踏襲し、取得後にメモリー内`mergeSort()`で適用する。 |

### グループ化

該当なし（GROUP BYはなし）。

### 取得項目

一覧検索の結果セットを再利用するため、出力項目は本ページ「3. 編集仕様＞項目定義（ヘッダー部／明細部）」の全59列を参照。

### 取得件数／0件時の扱い

| 項目              | 内容                             |
| ----------------- | ---------------------------------- |
| 取得件数          | 複数件 |
| 抽出結果0件の場合 | 0件時の特別処理（エラー表示・出力抑止等）なし（上記「0件出力」参照）。 |

## 3. 編集仕様

特別明記がない限り、値は元データの型のままExcelセルへ出力する（一覧画面と同様のサーバー側整形を経由）。桁数・数値フォーマットの詳細（切上／切捨／四捨五入等）はセル書式に依存し、ソースコードからは未特定。

### 項目定義（ヘッダー部／明細部）

全59列（`lyr07_U31DL.jsp` ヘッダー行、出力順）。

| No. | 出力項目名 |
| --- | ---------- |
| 1〜13 | 取引先コード／取引先略式名／製伝NO／品名／客先注番／分納NO／売上月／売上予定日／分納数量／単価／型代／売上予定金額／製造回答日 |
| 14〜21 | 客先回答日／製造残／営業残／在庫数／出荷数／在庫金額／売上実績金額／製伝納期 |
| 22〜30 | 約束納期／事業所コード／加工部門／事業部名／営業所コード／営業G／担当者コード／CSコード／客先PN |
| 31〜37 | 図番／品種1／品種2／品種2(1)／品種2(2)／品種2(3)／品種2(4) |
| 38〜45 | 送付先コード／AT区分／用途CD／出区／型代区分／TC／決済先名／SO |
