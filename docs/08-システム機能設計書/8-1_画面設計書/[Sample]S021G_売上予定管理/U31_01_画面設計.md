## 機能概要・関連画面一覧

本ページは画面`U31`単体の設計書。機能単位の情報（機能概要・本機能に属する画面の一覧）は
[index.md](index.md) の「1. 機能概要」「2. 関連画面一覧」を参照。

## 1. 画面レイアウト

実機画面キャプチャは未取得。構成は以下の通り。

- 上部：検索条件フォーム（`form1` → `lyr07_U31Servlet`）。全項目は「画面項目定義」の検索条件欄を参照。
- 検索条件の右側／上部に「検索条件1〜6」選択欄（`DEFAULT_NO`）— 保存済み検索条件セットのロード用。
- 中央：ボタン列（検索／今月売上／来月売上／再来月売上／更新／台帳検索／ダウンロード／検索条件保存／クリア）。
- 下部：検索結果グリッド（`form2`。1行＝1製伝の分納明細、ヘッダー行＋40列（先頭に行選択チェックボックス列）、行ごとにチェックボックス`DW_FLG`）。

## 2. 画面表示制御・表示パターン

| 項目               | 内容                                   |
| ------------------ | -------------------------------------- |
| 初期表示           | `initialEvent`／`reloadEvent` で画面を表示（検索条件欄は空、または「検索条件1〜6」で最後に保存した条件をロード）。検索ボタン押下まで一覧は表示されない。 |
| 前回検索条件の保存 | あり。「検索条件1」〜「検索条件6」（`DEFAULT_NO`＝`U31`〜`U36`）の最大6セットをユーザー単位で保存可能。「検索条件保存」ボタン押下時に `LYR03_DEF_TBL` へ保存（詳細は[更新条件表](U31_05_更新条件表/index.md)）。 |
| その他の表示パターン  | 「実績見込」チェック（`CHK_JISSEKI`）オンで検索元を実績系テーブルに切替。「製造回答表示」チェック（`CHK_KAITOU`）オンで明細のマージ方法（製造回答別／売上予定別）を切替。 |

## 3. 画面表示仕様
