# 検索条件表

/// tab | 本文


対象プロシージャー: `NOUKI_PKG.NOUKI_RENKEI`。宣言部で2つのCURSORが定義されている。

## 1. 基本情報

| 項目           | 内容                              |
| -------------- | ---------------------------------- |
| システムID     | AZR                                |
| DB(SQL)処理ID  | NOUKI_PKG                           |
| 作成日／作成者 | 不明（原設計書未受領のため未特定） |

## 2. 参照エンティティ一覧

| 記号 | 内容                            |
| ---- | ------------------------------- |
| C    | `CHUMON2`（ステージングテーブル） |
| N    | `NOUKI`（ステージングテーブル）   |

## 3. 検索条件表 No.1

| 項目 | 内容 |
| ---- | ---- |
| 概要 | 全注側から抽出したステージングデータ`CHUMON2`（C）を、会社コード固定条件で全件取得するカーソル |
| 用途 | 後続の検索条件表No.2（`nouki_cur`）呼び出しループの起点、および[処理概要](NOUKI_PKG_02_処理概要.md)手順3の重複行圧縮処理の対象データ取得 |

### 検索条件

| 検索対象テーブル | 演算子 | 条件項目名（参照先）        | 結合条件 | 必須 | 備考                     |
| ------------------ | ------ | ---------------------------- | -------- | ---- | ------------------------ |
| C                  | =      | `CompanyCD` = `'00'`（固定値） | -        | -    | パラメーターなし固定条件。`CURSOR chumon_cur IS SELECT * FROM CHUMON2 WHERE CompanyCD='00' ORDER BY CHUMON_NO, CHUMON_MEISAI_NO;` |

### 結合条件

該当なし（単一テーブル、JOINなし）。

### 抽出条件

該当なし（検索条件の固定値以外に抽出条件はない）。

### ソート順

| No. | 項目名               | ASC/DESC | 備考 |
| --- | ---------------------- | -------- | ---- |
| 1   | `CHUMON_NO`             | ASC      |      |
| 2   | `CHUMON_MEISAI_NO`      | ASC      |      |

### グループ化

該当なし（GROUP BYなし）。

### 取得項目

| No. | 取得項目名     | 取得できない場合 |
| --- | ---------------- | ---------------- |
| 1   | 全項目（`%ROWTYPE`） | 該当なし         |

### 取得件数／0件時の扱い

| 項目              | 内容                                                       |
| ----------------- | -------------------------------------------------------------- |
| 取得件数          | 複数件（カーソルループ処理）                                   |
| 抽出結果0件の場合 | 未調査（要確認。ループ自体が実行されないのみと推測されるが未確認） |

## 4. 検索条件表 No.2

| 項目 | 内容 |
| ---- | ---- |
| 概要 | 検索条件表No.1（`chumon_cur`）のループ内で1製伝No.（`chumonNo`）ごとに`NOUKI`（N）を検索するネストカーソル（パラメーター付き） |
| 用途 | 製伝No.単位の納期データ取得。後続の連携先テーブル群への反映処理の入力（[更新条件表](NOUKI_PKG_03_更新条件表.md)No.6参照） |

### 検索条件

| 検索対象テーブル | 演算子 | 条件項目名（参照先）                    | 結合条件 | 必須                                     | 備考                     |
| ------------------ | ------ | ------------------------------------------ | -------- | ------------------------------------------ | ------------------------ |
| N                  | =      | `CompanyCD` = `'00'`（固定値）              | AND      | -                                          |                          |
| N                  | =      | `CHUMON_NO` = 引数`chumonNo`                | AND      | 必須（検索条件表No.1のループ変数から渡される） | パラメーター付きカーソル。`CURSOR nouki_cur(chumonNo IN VARCHAR2) IS SELECT * FROM NOUKI WHERE CompanyCD='00' AND CHUMON_NO=chumonNo ORDER BY CHUMON_NO, NOKI_MEISAI_NO;` — No.1のループ内で1レコードずつ`chumonNo`を渡して開く「ネストカーソル」パターン（機能定義書の検索条件表にはない、バッチ/DB処理特有の構成） |

### 結合条件

該当なし（単一テーブル、JOINなし）。

### 抽出条件

該当なし（検索条件の固定値・引数以外に抽出条件はない）。

### ソート順

| No. | 項目名               | ASC/DESC | 備考 |
| --- | ---------------------- | -------- | ---- |
| 1   | `CHUMON_NO`             | ASC      |      |
| 2   | `NOKI_MEISAI_NO`        | ASC      |      |

### グループ化

該当なし（GROUP BYなし）。

### 取得項目

| No. | 取得項目名     | 取得できない場合 |
| --- | ---------------- | ---------------- |
| 1   | 全項目（`%ROWTYPE`） | 該当なし         |

### 取得件数／0件時の扱い

| 項目              | 内容                                                       |
| ----------------- | -------------------------------------------------------------- |
| 取得件数          | 複数件（カーソルループ処理）                                   |
| 抽出結果0件の場合 | 未調査（要確認。ループ自体が実行されないのみと推測されるが未確認） |

## 5. 備考

単発の単一行SELECT（`SELECT MAX(...) INTO ...`、`SELECT CD1 INTO ... FROM CODE_MST WHERE ...`）も
複数箇所にあるが、これらは検索条件表というより[更新条件表](NOUKI_PKG_03_更新条件表.md)No.4のチェック
ポイント読み取りに相当するため、そちらに記載している。
