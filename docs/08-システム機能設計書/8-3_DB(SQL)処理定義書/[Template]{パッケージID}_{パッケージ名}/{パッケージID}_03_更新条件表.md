## 2. 更新概要

1テーブル・1操作を1行とする（1項目を「、」「／」等で複数まとめない）。1オブジェクトが複数テーブルを
更新する場合はNo.を増やして列挙する。

- **更新種別**：`INSERT`／`UPDATE`／`DELETE`／`MERGE`／`TRUNCATE`のいずれかを記載する
  （`MERGE`の場合は、一致時（UPDATE側）・不一致時（INSERT側）の設定内容を「3. 更新条件・更新項目」で
  それぞれ分けて記載する。`TRUNCATE`の場合は更新項目は「該当なし（全件削除）」とする）。
- **スキーマ名とテーブル名は列を分ける**（1セルに`スキーマ.テーブル`の形で混ぜない）。
- 更新条件・更新項目の詳細は「3. 更新条件・更新項目」に操作No.ごとに記載する。

#### 更新条件

WHERE句・MERGEのON句の条件を、実際の条件式の形で記載する（該当なしの場合は「該当なし（全件対象）」と明記）。

```text
■UPDATE①-条件
D.項目A = 引数1 AND
D.項目B = 引数2
```
