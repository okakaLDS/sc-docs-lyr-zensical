# ファイル入力仕様

/// tab | 本文


## 1. 基本情報

| 項目       | 内容                                    |
| ---------- | --------------------------------------- |
| ファイルID | （ID可変。`<ID>_00*`）。世代管理用ステータスファイルそのものは業務データではないため6-5_ファイル一覧の対象外 |
| システムID | LYR19                                   |
| 処理ID     | COMM_ftp                             |
| ファイル名 | `<ID>_00*.sts`（ステータス）／解凍後`.\UPLOAD_DAT\<ID>.*`（データ） |
| 連携元     | 経管FTPサーバー（呼出元により接続先が変わりうる。FVCC007では`zea99-ftp10.ca.kyocera`。他IDの接続先は未確認） |
| 作成日     | （記入：ソース内ヘッダーコメント未確認）      |
| 作成者     | （記入：同上）            |

## 2. 入力ファイル設定

| 項目                 | 内容                                                                             |
| -------------------- | -------------------------------------------------------------------------------- |
| 拡張子               | データファイルは`.lzh`／`.gz`／`.zip`の圧縮形式もありうる（拡張子で解凍方式を分岐） |
| 取得元ディレクトリー   | FTPサーバーのカレントディレクトリー（FVCC007の`ftpCfgT.cfg`にディレクトリー移動の指定なし。他IDは未確認） |
| ファイル名の命名規則 | ステータスファイル：`<ID>_00*.sts`。データファイル名は`.sts`内の`ATTACHMENT:`行から取得する |
| 最大データ件数       | 該当なし（本エンジンはファイル転送のみを行い、レコード単位の件数制御は`go<ID>.bat`側） |
| 文字コード           | （記入：`.sts`自体の文字コードは未確認。データファイルの文字コードはID固有のためID側フォルダー参照） |
| BOM                  | （記入：未確認）                       |
| 改行コード           | （記入：未確認）                       |
| レコード長           | 該当なし（`.sts`はテキスト形式のステータスファイル。データファイルのレコード長はID固有） |
| 囲み文字／区切り文字 | 該当なし（本エンジンの対象は`.sts`）                 |
| ヘッダー（見出し行）   | 該当なし                               |

## 3. 取込方式

本エンジンはSQL\*Loader等へのDB取込は行わない（ファイル転送・解凍まで）。取込方式（`.ctl`定義等）は
`go<ID>.bat`自身のフォルダーを参照（例：[goFVCC011のファイル入力仕様](<../[Sample]goFVCC011/goFVCC011_06_ファイル入力仕様.md>)）。

## 4. 入力項目

`.sts`ファイルの主要行：

| No. | 行キー | 内容 | 用途 |
| --- | ------ | ---- | ---- |
| 1   | `ATTACHMENT-Name:` | データファイル名 | データファイルのFTP取得時のファイル名指定 |
| 2   | `TIME:`            | 生成時刻 | 世代比較（降順ソートの1件目を最新とする） |

データファイル自体の入力項目（レコードレイアウト）はID固有のためエンジン側では管理しない。

## 5. 取込制御

| 項目                     | 内容                                                                                       |
| ------------------------ | -------------------------------------------------------------------------------------------- |
| ファイル未存在時の扱い   | `.sts`が取得できない場合の挙動は未確認（要ソース追加調査） |
| データ0件時の扱い        | 該当なし |
| 不正レコード検出時の扱い | 該当なし（レコード単位の検証は`go<ID>.bat`側） |
| 重複レコード検出時の扱い | 同一世代の二重取込は`.sts`の世代比較（`*_stsListSortO.tmp`との比較）で防止する |
| 取込後のファイル処理     | 中間ファイル（`*.tmp`等）は退避・削除されない。次回実行時に本エンジンの冒頭で削除される（FVCC007のソース確認による） |
