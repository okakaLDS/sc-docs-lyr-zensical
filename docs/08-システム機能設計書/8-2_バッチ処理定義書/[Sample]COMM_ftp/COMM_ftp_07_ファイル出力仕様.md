# ファイル出力仕様

/// tab | 本文


## 1. 基本情報

| 項目       | 内容                       |
| ---------- | -------------------------- |
| ファイルID | 該当なし（業務データファイルの出力は行わない） |
| システムID | LYR19                      |
| 処理ID     | COMM_ftp                |
| ファイル名 | 下記「出力ファイル設定」参照 |
| 作成日     | （記入：ソース内ヘッダーコメント未確認） |
| 作成者     | （記入：同上） |

## 2. 出力条件

本エンジンはDBから抽出したデータをファイル化する処理を持たない。出力されるのは中間ファイル・制御ファイルのみ。

| 項目     | 内容     |
| -------- | -------- |
| 抽出条件 | 該当なし |
| 検索条件 | 該当なし |
| 結合条件 | 該当なし |
| ソート順 | 該当なし |
| 集約     | 該当なし |

## 3. 出力ファイル設定

（ID可変。`<ID>`は呼出元から渡される第1引数。排他フラグ`go<ID>.flg`は本エンジンが作成・削除するため下表に含む。
`go<ID>.bat`自身が出力するログ・不良レコードは本エンジンの対象外。実例は
[goFVCC011のファイル出力仕様](<../[Sample]goFVCC011/goFVCC011_07_ファイル出力仕様.md>)参照）

| ファイル                             | 種別         | 形式             | 内容                                                             |
| ------------------------------------ | ------------ | ---------------- | ------------------------------------------------------------------ |
| `FTP_CMD\<ID>_sts_ftp.tmp`        | 中間ファイル | テキスト         | `.sts`取得用に生成したFTPコマンド                                |
| `FTP_CMD\<ID>_dat_ftp.tmp`        | 中間ファイル | テキスト         | データファイル取得用に生成したFTPコマンド                        |
| `<ID>_stsList.tmp`                | 中間ファイル | テキスト         | 対象IDを含む`.sts`のファイル名一覧                               |
| `<ID>_stsListTime.tmp`            | 中間ファイル | テキスト         | `.sts`の`TIME:`行をソートしたもの                                |
| `<ID>_stsListSort.tmp`            | 中間ファイル | テキスト         | 今回の世代一覧（時刻:ファイル名）                                |
| `<ID>_stsListSortO.tmp`           | 中間ファイル | テキスト         | 前回の世代一覧。世代重複チェックに使用する                       |
| `<ID>_datSize.tmp`                | 中間ファイル | テキスト         | FTP転送元のファイルサイズ一覧                                    |
| `go<ID>.flg`                      | 制御ファイル | 空ファイル       | 多重起動防止の排他フラグ。`go<ID>.bat`呼出後に削除される      |

業務データ・ログファイル（実行ログ／SQL\*Loaderログ）はID固有のため`go<ID>.bat`側（各処理IDフォルダー）で管理する。

## 4. 出力項目

業務データファイルを出力しないため、項目名／桁数／型といった明細仕様は該当なし。
