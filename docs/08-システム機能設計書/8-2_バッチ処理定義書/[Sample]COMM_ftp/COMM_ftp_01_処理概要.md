## 2. 機能概要

ファイルID（例：`FVCC007`）を第1引数として受け取り、次を汎用的に行う共通部品。

1. 前回データファイルの削除、排他フラグの確認
2. FTP接続し、対象IDのステータスファイル（`<ID>_00*.sts`）を取得
3. `.sts`の`TIME:`行から生成時刻を比較し、**最新1世代のみ**を選択（前回世代と同一なら処理打ち切り）
4. 最新世代のデータファイルをFTPでbinary取得し、転送元／転送先のサイズを照合（不一致時は1回だけ再転送）
5. 拡張子（`.lzh`／`.gz`／`.zip`）に応じて解凍
6. 排他フラグを作成し、`go<ID>.bat`（呼出元の処理ID固有のロード処理）を呼び出す

DB取得・DB更新・業務データの入出力は行わない。**`go<ID>.bat`以降の処理（DBロード・差分反映等）は
`go<ID>.bat`自身のフォルダー（例：[goFVCC011](<../[Sample]goFVCC011/index.md>)）に記載する。**

## 3. 起動・実行条件

起動時刻・反復間隔等、Windowsタスクスケジューラの設定情報（xlsx）に由来する内容は、本ファイルの
ソースコードには含まれないため対象外とする。

| 項目                     | 内容     |
| ------------------------ | -------- |
| 実行契機・パラメーター     | 第1引数＝ファイルID（例：`FVCC011`）。呼出元ラッパーが固定値で渡す |
| 多重起動の可否／排他制御 | 排他フラグファイル`go<ID>.flg`で制御。存在する場合は`"DATA uploading(SQLLoader Process)"`を出力し即終了する |

## 4. 実行環境・前提

実行サーバー・実行ユーザはタスクスケジューラの設定情報であり、本ファイルのソースコードから
特定できないため対象外とする。

| 項目                         | 内容     |
| ---------------------------- | -------- |
| 実行ディレクトリー             | `%LYR_SQLBAT_DIR%`（呼出元ラッパーが`CD`してから呼び出す） |
| 必要な環境変数               | `%LYR_SQLBAT_DIR%`（実行ディレクトリー）。設定元はソース内に無く未確認 |
| 依存ミドルウェア・外部ツール | Windows標準`ftp`コマンド、解凍ツール（`LHASA\LHASA.EXE`／`PRG\7z1900-extra\7za.exe`） |

## 5. データベース CRUD

該当なし。本エンジンはDBへ直接アクセスしない（DB操作は`go<ID>.bat`側で行われ、各処理IDのフォルダーで管理する）。

## 6. ファイル I/O

- 入力（I）の詳細は[ファイル入力仕様](COMM_ftp_06_ファイル入力仕様.md)を参照。
- 出力（O）の詳細は[ファイル出力仕様](COMM_ftp_07_ファイル出力仕様.md)を参照。

| ファイルID | ファイル名 | I（入力） | O（出力） | 備考 |
| ---------- | ---------- | --------- | --------- | ---- |
| （ID可変） | `<ID>_00*.sts`（ステータスファイル） | ● |  | 世代管理用。実ファイル名はIDにより変わる |
| （ID可変） | データファイル（拡張子は連携元依存） | ● |  | 解凍後、呼出元の`UPLOAD_DAT\<ID>.*`として配置 |
