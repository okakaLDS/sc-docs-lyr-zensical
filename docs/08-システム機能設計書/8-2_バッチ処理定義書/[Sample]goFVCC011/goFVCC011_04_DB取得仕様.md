## 2. 取得処理一覧

| No. | 処理概要                                                              | 処理種別 |
| --- | ----------------------------------------------------------------------- | -------- |
| 1   | `CB46`へ未反映の未納データを`FVCC011`から抽出する                       | SELECT   |
| 2   | 取込件数情報を`SQLLDR_UPDATE_TMP`から抽出する                           | SELECT   |
| 3   | `CB46`の関連会社コード未設定行に対し、`FVCF006`から関連会社コードを取得する | SELECT   |
| 4   | `CB46`の関連会社コード未設定行に対し（No.3で埋まらなかった場合）、`FVCF303`から関連会社コードを取得する | SELECT   |

## 3. No.1: `CB46`へ未反映の未納データを`FVCC011`から抽出する

| 項目              | 内容                                                                           |
| ----------------- | ------------------------------------------------------------------------------ |
| 対象テーブル      | `FVCC011`（テーブル論理名は本ソース範囲内に記載が無く未確認。（記入：DBレイアウト定義書で確認要）） |
| 結合条件（JOIN）  | 該当なし                                                                       |
| 抽出条件（WHERE） | `FVCC011.HAISHIN_BI > (SELECT NVL(MAX(HAISHIN_BI),'20100101') FROM CB46)`      |
| ソート順          | 該当なし（`ORDER BY`の指定なし）                                               |
| 取得件数          | 複数件                                                                         |
| 抽出結果0件の場合 | `INSERT ... SELECT`が0件挿入となるのみ。エラーとせず後続処理を継続する         |

### 取得カラム

`CB46`へ`INSERT`する95項目を`FVCC011`から取得する。項目の対応関係（編集内容を含む）は
[更新条件表](goFVCC011_05_更新条件表.md)の「更新カラム詳細」に記載する。

## 4. No.2: 取込件数情報を`SQLLDR_UPDATE_TMP`から抽出する

| 項目              | 内容                                                     |
| ----------------- | -------------------------------------------------------- |
| 対象テーブル      | `SQLLDR_UPDATE_TMP`                                      |
| 結合条件（JOIN）  | 該当なし                                                 |
| 抽出条件（WHERE） | `MAIL_CD = 'FVCC011'`                                    |
| ソート順          | 該当なし                                                 |
| 取得件数          | 単一件（連携ファイルのトレーラレコード1件に対応）        |
| 抽出結果0件の場合 | ソース上、0件時の分岐処理は無い                          |

### 取得カラム

| No. | カラム名       | 論理名             | 取得元テーブル      | 備考                                     |
| --- | -------------- | ------------------ | ------------------- | ---------------------------------------- |
| 1   | `DATA_KBN`     | データ区分         | `SQLLDR_UPDATE_TMP` |                                          |
| 2   | `MAIL_CD`      | メールコード       | `SQLLDR_UPDATE_TMP` | `SQLLDR_UPDATE_LOG`へは値をそのまま登録／`SQLLDR_UPDATE`へは`'CBB8'`固定で登録する |
| 3   | `CREATED_DATE` | 作成日時           | `SQLLDR_UPDATE_TMP` | ロード時に`NENGETSU + JIKAN`から生成     |
| 4   | `PHYSICAL_CNT` | 物理件数           | `SQLLDR_UPDATE_TMP` |                                          |
| 5   | `RECORD_CNT`   | レコード件数       | `SQLLDR_UPDATE_TMP` |                                          |
| 6   | `DATA_LOCK`    | データロック       | `SQLLDR_UPDATE_TMP` |                                          |

## 5. No.3・No.4: `CB46`の関連会社コード補完

| 項目              | No.3（`FVCF006`）                                                              | No.4（`FVCF303`）                                                              |
| ----------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 対象テーブル      | `FVCF006`                                                                       | `FVCF303`                                                                       |
| 結合条件（JOIN）  | 相関副問合せ：`B.SEIDEN_NO = CB46.SEIDEN_NO`                                    | 相関副問合せ：`B.SEIDEN_NO = CB46.SEIDEN_NO`                                    |
| 抽出条件（WHERE） | `CB46.HAISHIN_BI >= TO_CHAR(SYSDATE-50,'YYYYMMDD') AND CB46.KANREN_KAISHA_CD IS NULL`（`UPDATE`側の絞り込み条件） | 同左                                                                            |
| ソート順          | 該当なし（`ROWNUM = 1`で1件に限定）                                              | 該当なし（`ROWNUM = 1`で1件に限定）                                              |
| 取得件数          | 単一件（`DISTINCT`＋`ROWNUM = 1`）                                              | 単一件（同左）                                                                  |
| 抽出結果0件の場合 | `UPDATE`の`SET`句が`NULL`となり、対象行の`KANREN_KAISHA_CD`は`NULL`のまま（次のNo.4で再評価される） | `UPDATE`の`SET`句が`NULL`となり、対象行の`KANREN_KAISHA_CD`は`NULL`のまま残る（以降の再評価なし） |

### 取得カラム

| No. | カラム名                | 論理名           | 取得元テーブル | 備考 |
| --- | ----------------------- | ---------------- | -------------- | ---- |
| 1   | `SHUUKEI_CD_MEISAI`     | 集計コード（明細）| `FVCF006`／`FVCF303` | `CB46.KANREN_KAISHA_CD`へ設定 |
