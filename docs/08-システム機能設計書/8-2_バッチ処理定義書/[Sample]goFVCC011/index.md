| 項目            | 内容                                                              |
| --------------- | ----------------------------------------------------------------- |
| バッチ名        | CB46連携データ取込（未納処理連携）— ロード・差分反映処理           |
| バッチ分類      | FTP Flow（バッチ一覧 No.7）                                       |
