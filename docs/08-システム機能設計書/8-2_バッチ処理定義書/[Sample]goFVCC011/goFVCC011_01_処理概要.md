## 2. 機能概要

> 共通バッチエンジン`COMM_ftp.bat`がFTPから取得・解凍した連携ファイル`.\UPLOAD_DAT\FVCC011.tsv`が
> 存在する場合のみ、以下を実行する：`FVCC011before_load.sql`で更新ステータスを取込中に設定 →
> SQL\*Loaderで`FVCC011`（明細）／`SQLLDR_UPDATE_TMP`（トレーラ）へロード →
> `FVCC011after_load.sql`でステータス復帰・取込履歴登録・未納処理テーブル`CB46`への差分反映・
> 関連会社コード補完（`FVCF006`／`FVCF303`）を行いコミットしたうえで、ストアドプロシージャー
> `SP_MINOU_SYORI_2021`を実行する。

## 3. 起動・実行条件

本ファイル自体はタスクスケジューラへの単独登録が無く、起動時刻はWindowsタスクスケジューラの
設定情報（本ファイルのソースコードには含まれない）に依存するため対象外とする。

| 項目                     | 内容                                                                                     |
| ------------------------ | ---------------------------------------------------------------------------------------- |
| 起動方法                 | 共通バッチエンジン`COMM_ftp.bat`からの`call`（引数なし）                                  |
| 実行契機・パラメーター     | 引数なし。呼出元（`COMM_ftp.bat`）と同一ディレクトリー・同一環境変数（`%LYR_SQLCONNECT%`）を前提とする |
| 多重起動の可否／排他制御 | 排他フラグ`goFVCC011.flg`で制御されるが、**フラグの作成・削除は本ファイルではなく呼出元の`COMM_ftp.bat`が行う**（本ファイル自体にフラグ操作のコードは無い） |

## 4. 実行環境・前提

| 項目                         | 内容                                                                                  |
| ---------------------------- | --------------------------------------------------------------------------------------- |
| 実行ディレクトリー             | `%LYR_SQLBAT_DIR%`（呼出元`COMM_ftp.bat`のカレントディレクトリーを引き継ぐ）              |
| 必要な環境変数               | `%LYR_SQLCONNECT%`（Oracle接続文字列）。設定元はソース内に無く未確認                     |
| 依存ミドルウェア・外部ツール | Oracle SQL\*Plus、Oracle SQL\*Loader（`sqlldr`）                                         |

実行サーバー・実行ユーザはタスクスケジューラの設定情報であり、本ファイルのソースコードから
特定できないため対象外とする。
