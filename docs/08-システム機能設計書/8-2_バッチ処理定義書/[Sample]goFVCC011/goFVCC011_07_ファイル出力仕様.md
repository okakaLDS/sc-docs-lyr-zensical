# ファイル出力仕様

/// tab | 本文


## 1. 基本情報

| 項目       | 内容                       |
| ---------- | -------------------------- |
| ファイルID | 該当なし（業務データファイルの出力は行わないため、6-5_ファイル一覧への登録対象外） |
| システムID | LYR19                      |
| 処理ID     | goFVCC011                  |
| ファイル名 | 下記「出力ファイル設定」参照 |
| 作成日     | 不明（`goFVCC011.bat`にヘッダーコメントなし） |
| 作成者     | 不明（同上）                |

## 2. 出力条件

本バッチはDBから抽出したデータをファイル化する処理を持たない。出力されるのはログ・不良レコードのみ。
排他フラグ`goFVCC011.flg`は本ファイルではなく呼出元の共通バッチエンジン`COMM_ftp.bat`が作成・削除する
（詳細は[COMM_ftp](<../[Sample]COMM_ftp/index.md>)参照）。

| 項目     | 内容     |
| -------- | -------- |
| 抽出条件 | 該当なし |
| 検索条件 | 該当なし |
| 結合条件 | 該当なし |
| ソート順 | 該当なし |
| 集約     | 該当なし |

## 3. 出力ファイル設定

| ファイル                          | 種別         | 形式             | 内容                                                       |
| ---------------------------------- | ------------ | ---------------- | ------------------------------------------------------------ |
| `LOG\LYR07_FVCC011.log`            | 実行ログ     | テキスト（追記） | 開始／終了時刻、SQL\*Plusの標準出力                        |
| `LOG\loading_011.log`              | ツールログ   | SQL\*Loader標準  | 取込件数・エラー内容（実行ごとに上書き）                    |
| `.\UPLOAD_DAT\FVCC011.bad`          | 不良レコード | 入力と同形式     | SQL\*Loaderがロードできなかったレコード                     |

## 4. 出力項目

業務データファイルを出力しないため、項目名／桁数／型といった明細仕様は該当なし。
