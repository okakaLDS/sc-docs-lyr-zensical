## 2. 設計書構成

本ファイルは共通バッチエンジンを呼び出すだけの薄いラッパー（2行）であり、8項目のうち
本体に固有の内容を持つのは「1. 処理概要」「8. 外部リクエスト仕様」のみ。
残りは本ファイル自体に該当する内容が無いため作成しない（対象外）。

| No. | 設計書名                   | 作成有無 | 本フォルダーでの対応ページ／対象外の理由                                        |
| --- | -------------------------- | -------- | ------------------------------------------------------------------------------ |
| 1 | 処理概要 | 作成 | [処理概要](COMM_FTP_FVCC011_01_処理概要.md) |
| 2 | 処理フロー | 対象外 | 本体はコマンド1行のみで分岐・処理ステップが無く、フロー図・処理ステップが処理概要と別に持つ情報が無いため。実行順序（後続＝`COMM_ftp.bat`）は[外部リクエスト仕様](COMM_FTP_FVCC011_08_外部リクエスト仕様.md)「3. 呼び出し一覧」で読める |
| 3 | チェック処理概要 | 対象外 | 本体に条件分岐・チェック処理を持たない |
| 4 | DB取得仕様 | 対象外 | 本体はDBへ接続しない |
| 5 | 更新条件表 | 対象外 | 本体はDBを更新しない |
| 6 | ファイル入力仕様 | 対象外 | 本体はファイルを読み込まない（ファイル取得は[COMM_ftp](<../[Sample]COMM_ftp/index.md>)が行う） |
| 7 | ファイル出力仕様 | 対象外 | 本体はファイルを出力しない（ログ等の出力は呼出し先が行う） |
| 8 | 外部リクエスト仕様 | 作成 | [外部リクエスト仕様](COMM_FTP_FVCC011_08_外部リクエスト仕様.md) |
