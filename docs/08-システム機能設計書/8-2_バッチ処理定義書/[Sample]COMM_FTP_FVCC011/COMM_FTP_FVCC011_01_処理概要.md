# 処理概要

## 1. 基本情報

| 項目               | 内容                                        |
| ------------------ | ------------------------------------------- |
| システムID         | LYR19                                       |
| システム名         | SC納期管理                                  |
| 処理ID             | COMM_FTP_FVCC011                            |
| 機能名グループ     | FTP Flow                                    |
| 機能名（バッチ名） | CB46連携データ取込（未納処理連携）— 起動ラッパー |
| プログラムID       | `COMM_FTP_FVCC011.bat`                      |
| 作成日             | 不明（ソース内に作成日コメントなし）        |
| 作成者             | 不明（同上）                                |

## 2. 機能概要

> 本体のソースは以下の2行のみ。
>
> ```bat
> CD %LYR_SQLBAT_DIR%
> .\COMM_ftp.bat FVCC011
> ```
>
> 自身は固有のDB操作・ファイル入出力を一切持たず、共通バッチエンジン`COMM_ftp.bat`を
> ファイルID`FVCC011`を引数として呼び出すだけの起動ラッパーである。実際のFTP取得・解凍・
> ロード・差分反映処理は呼出し先（[COMM_ftp](<../[Sample]COMM_ftp/index.md>)と
> [goFVCC011](<../[Sample]goFVCC011/index.md>)）が行う。

## 3. 起動・実行条件

本ファイル単体の起動契機（どのタスクから・いつ呼ばれるか）はWindowsタスクスケジューラの設定
情報であり、本ファイルのソースコードには含まれないため対象外とする（ソースコードから抽出できる
情報のみを本書に記載する方針のため）。

| 項目                     | 内容                                                                                     |
| ------------------------ | ---------------------------------------------------------------------------------------- |
| 実行契機・パラメーター     | 引数なし。本体内で固定文字列`FVCC011`を`COMM_ftp.bat`の第1引数として渡す                  |
| 多重起動の可否／排他制御 | 本体自身は排他制御を持たない（ソース2行に該当コードなし）。呼出し先`COMM_ftp.bat`側の制御は[COMM_ftp](<../[Sample]COMM_ftp/index.md>)参照 |

## 4. 実行環境・前提

| 項目                         | 内容                                                                                  |
| ---------------------------- | --------------------------------------------------------------------------------------- |
| 実行ディレクトリー             | `%LYR_SQLBAT_DIR%`（本体冒頭で`CD`する）                                                |
| 必要な環境変数               | `%LYR_SQLBAT_DIR%`（実行ディレクトリー）。設定元はソース内に無く未確認                     |
| 依存ミドルウェア・外部ツール | なし（本体自身は`COMM_ftp.bat`を呼ぶのみ）                                              |

実行サーバー・実行ユーザはタスクスケジューラの設定情報であり、本ファイルのソースコードから
特定できないため対象外とする。

## 5. データベース CRUD

本体自身はDBに接続しない（対象外）。呼出し先のCRUDは[goFVCC011](<../[Sample]goFVCC011/index.md>)側を参照。

## 6. ファイル I/O

本体自身はファイルの読み書きを行わない（対象外）。取得・出力されるファイルは呼出し先
（[COMM_ftp](<../[Sample]COMM_ftp/index.md>)、[goFVCC011](<../[Sample]goFVCC011/index.md>)）側を参照。
