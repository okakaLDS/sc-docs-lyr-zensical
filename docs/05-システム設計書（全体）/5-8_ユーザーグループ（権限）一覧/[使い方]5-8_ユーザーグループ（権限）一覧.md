# ユーザーグループ（権限）一覧 — 使い方

*記入用の様式は [空テンプレート](<[Template]5-8_ユーザーグループ（権限）一覧.md>)、記入例は [サンプル](<[Sample]5-8_ユーザーグループ（権限）一覧.md>) を参照。*

## 1. 参考様式

*全注（全注文システム）基本設計書 `Ⅳ-8.ﾕｰｻﾞｰｸﾞﾙｰﾌﾟ(権限)一覧.xlsx` の構成に合わせている。
見出し番号・表の列は全注の実ファイルのものを踏襲している。本システムで不要な列は削ってよい。*

## 2. 権限制御の全体像

> **📌 権限は2階層で制御する**
>
> *全注の原本では、**メニューグループ**と**権限コード**という別々の仕組みで段階的に制御していた。役割が違うので混同しないこと。*
>
> | 仕組み | 制御する対象 | 定義場所 |
> | ------ | ------------ | -------- |
> | **メニューグループ** | どのメニュー（画面）が見えるか | [メニュー構成表](<../5-7_メニュー構成表/[Template]5-7_メニュー構成表.md>) |
> | **権限コード** | 画面内で何ができるか（項目の活性／非活性、照会できるデータの範囲） | 本ドキュメント |

## 3. 各節の書き方

| 節 | 書くこと |
| -- | -------- |
| 1. ユーザー情報の項目 | ユーザーマスターが保持する項目。「必須」は登録時の必須入力。入力の初期表示に使うだけの項目や、他システム連携のためだけに持つ項目（画面から変更不可）も列挙する（全注は15項目） |
| 2. 権限コードの桁構成 | 1桁1権限のコード体系。各桁は `0:無し` / `1:有`。桁数は権限の種類の数だけ用意（全注は4桁） |
| 3. 役割と権限コードの対応 | 業務上の役割ごとに割り当てる権限を `○`/`×` で定義 |
| 4. メニューグループ一覧 | メニューグループのコードと名称。[メニュー構成表](<../5-7_メニュー構成表/[Template]5-7_メニュー構成表.md>) の列見出しと一致させる（全注は 10/20/…/90 の10刻みで90を管理者に充当。途中追加できるよう間隔を空ける） |

> **📌 コード値と実効権限が一致しないケースに注意**
>
> *全注では、システム管理者の権限コードが `0001` でありながら、実際にはCS・営業・責任者すべての権限を持つ設定だった。
> **上位権限が下位権限を包含する**場合、コードのビットをそのまま読むと誤る。包含関係があるときは役割対応表の○×で実効権限を明示し、備考に理由を書く。*
