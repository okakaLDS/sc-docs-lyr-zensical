# 概略オペレーションフロー — 使い方

*記入用の様式は [空テンプレート](<[Template]5-2_概略オペレーションフロー.md>)、記入例は [サンプル](<[Sample]5-2_概略オペレーションフロー.md>) を参照。*

## 1. 参考様式・概要

*全注（全注文システム）基本設計書 `Ⅳ-2.概略ｵﾍﾟﾚｰｼｮﾝﾌﾛｰ.xlsx` の構成を参考にしている。画面がどの順序で表示され、画面同士がどう関連するか（連携システム・帳票への遷移を含む）を示す。*

本サイトでは **「部門 → 機能ID（OPFパッケージ）」の単位**でフローを作る。機能IDは [システム機能一覧（6.1）](<../../06-システム設計書（一覧、管理台帳）/6-1_システム機能一覧/[Sample]6-1_システム機能一覧.md>) の機能ID列（例：`P001A`）＝OPFパッケージ（1機能ID＝複数のJSP画面をまとめる単位）で、その並び（部門 → 機能分類 → 機能ID）に対応させる。

## 2. 凡例

**画面を起点に、ボタン名をラベルにした矢印で遷移先（画面・帳票）へ枝分かれさせる `flowchart`** で描く。

| Mermaidの記法 | 形・見た目 | 意味 |
| ------------- | ---------- | ---- |
| `A["画面名（画面ID）"]` | 長方形 | 画面 |
| `A[/"帳票名"/]` | 平行四辺形 | 帳票（印刷・出力） |
| `A -->\|ボタン名\| B` | 矢印 | 画面遷移・操作（ラベル＝ボタン名／リンク名） |
| `A ==>\|ボタン名\| B` | 太矢印 | **主フロー**（順路の中心。使う場合） |
| `A -.->\|〜\| B` | 点線矢印 | 外部システムへの遷移 |
| `subgraph 名` | 囲み | グルーピング（必要な場合） |

*矢印のラベルは**アクション（ボタン名・リンク名）**を書く。画面IDは [画面・帳票一覧（6.2）](<../../06-システム設計書（一覧、管理台帳）/6-2_画面・帳票一覧/[Sample]6-2_画面・帳票一覧.md>) と一致させる。図に描くと煩雑になる詳細（区分＝主フロー／副次／外部／帳票出力）は、各フローの「手順・遷移表」で補完する。*

## 3. 構成の考え方（部門×機能ID別フロー）

- 章立ては `## {部門}` → `### {機能ID} {機能名}`（6.1 の部門・機能IDに合わせる）。
- 実際に利用されている画面は、**必ずどこかのフローに登場する**。そのため**全体画面遷移図は作らない**。
- **同一画面IDは複数のフローに登場してよい**（ハブ／共有画面は関係する各フローに現れる。「1回だけ」ルールは設けない）。

> **📌 網羅性は「全画面がどこかのフローに登場する」ことで担保する**
>
> *抜け漏れ確認は、[画面・帳票一覧（6.2）](<../../06-システム設計書（一覧、管理台帳）/6-2_画面・帳票一覧/[Sample]6-2_画面・帳票一覧.md>) の各画面IDが本書のいずれかのフローに1回以上登場するかを、レビュー時に突合して行う（常設の対応表は持たず二重管理を避ける）。画面台帳は 6.2 が正で本書に再掲しない。*

> **📌 3-1 業務フローとの違い（重複させない）**
>
> *本節は「システムを**どの画面→どの画面**で操作するか」に特化する（**画面遷移図／画面ID**）。業務全体の流れ（社外・営業・製造など組織横断、電話・紙などシステム外を含む）は [業務フロー（3-1）](<../../03-業務設計書/3-1_業務フロー/[Template]3-1_業務フロー.md>) が正。画面内部の詳細は機能定義書（8章）へ委ねる。*

## 4. 各節の書き方（統一様式の構成）

| 節 | 書くこと |
| -- | -------- |
| 1. 全画面共通の遷移ルール | どの画面からも遷移できる先など、図に描くと線だらけになるルールを文章・表で書く |
| 2. 利用ユーザー種別 | 種別で利用画面が異なる場合に記述。どの権限が使えるかは [ユーザーグループ（権限）一覧（5-8）](<../5-8_ユーザーグループ（権限）一覧/[Template]5-8_ユーザーグループ（権限）一覧.md>) と対応させる |
| 3. 部門×機能ID別フロー | 部門→機能IDごとに、**画面遷移図（`flowchart`）** を描き、直下に**手順・遷移表**（図の表バックアップ。区分で主フロー／副次／外部／帳票出力を表す）を添える。**手順・遷移表は必須**（表が正、図はその可視化。2026-09-03 客先合意で様式確定） |
| 4. 共通系画面（後日追加） | 部門「共通」や複数機能から共有される共通系画面。SC側で把握し切れていないため、画面設計書等が揃った後に追加（判明するまで網羅チェックの対象から暫定除外と明記） |
| 5. スコープ外の画面 | 将来対応予定だが今回作らない画面／未使用の画面を残す |

*旧「原案（起点終点＋1本の画面遷移図）」と「新案（全体画面遷移図＋業務工程別フロー）」は本様式に一本化した。粒度は部門×機能ID別フロー、図法・必要項目は原案の画面遷移図（`flowchart`）＋全画面共通ルール・利用ユーザー種別・手順/遷移表・スコープ外画面を取り込んでいる。*
