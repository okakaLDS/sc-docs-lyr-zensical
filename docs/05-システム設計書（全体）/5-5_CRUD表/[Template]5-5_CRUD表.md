## 2. 凡例

| 記号   | 意味                                                                     |
| ------ | ---------------------------------------------------------------------------- |
| 区分＝画面 | その行がWebシステムの画面であることを示す（画面/バッチID・画面/バッチ名称欄には画面ID・画面名称を記載）    |
| 区分＝バッチ | その行がバッチ処理であることを示す（画面/バッチID・画面/バッチ名称欄にはバッチID・バッチ名を記載）        |
| C      | Create（そのテーブルにレコードを新規作成する）                            |
| R      | Read（そのテーブルを参照する）                                            |
| U      | Update（そのテーブルのレコードを更新する）                                |
| D      | Delete（そのテーブルのレコードを削除する）                                |
| CRUD等の組み合わせ表記 | その画面/バッチがそのテーブルに対して行う操作の組み合わせ（例："CRUD"＝C・R・U・D全て行う、"RU"＝参照と更新のみ） |
| 空欄   | その画面/バッチとそのテーブルの間に関係がない（一切アクセスしない）              |
