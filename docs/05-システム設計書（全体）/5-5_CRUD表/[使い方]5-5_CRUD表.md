# CRUD表（使い方）

## 1. 使い方

このファイルは新しいCRUD表ページを追加する際の**空のひな形**（実データを含まない）。記入例（架空データ）は
[\[Sample\]5-5_CRUD表](<[Sample]5-5_CRUD表.md>) を参照する（実データ版はソースコードからの抽出後に差し替える）。

**追加手順**

1. 参照元Excel（またはDB定義）の元マトリクス（行＝画面、列＝テーブル、交点＝C/R/U/D）を確認する。
2. **行**は機能ごとにグループ化し、その機能に属する画面を並べる（1行＝1画面）。元Excelでは機能ID・
   機能名称をその機能内の最初の行にのみ記載し縦方向にセル結合しているが、マークダウン表にはセル結合が
   無いため、**その機能に属する全ての行に同じ機能ID・機能名称を繰り返して記載**する（空欄にしない。
   下記「共通の記入ルール — グループ化した行でもキー列を空欄にしない」を参照）。
3. **列**は1列＝1物理テーブルとし、列見出し（物理テーブル名／論理名）は`[Sample]5-4_排他マトリクス.md`
   と同じ`<span style="writing-mode: vertical-rl;">…</span>`で縦書き表示にし、横幅を抑える（元Excelの
   列見出し回転と同じ考え方）。DB内の全テーブルを対象とし、使用画面数が0件のテーブルも列を省略せず
   記載する（改修時にどのテーブルが未使用かを判別できるようにするため）。
4. **交点**にはその画面がそのテーブルに対して行うC/R/U/Dの組み合わせ（例："CRUD"、"RU"）を記載する。
   関係がない交点は空欄とする。

## 共通の記入ルール

「ほか」「等」での省略禁止／1件＝1行／グループ化した行でもキー列を空欄にしない、の3点は [記述ルール 節10「列挙と行の書き方」](<../5-9_標準設計書/5-9-1_記述ルール/[Sample]5-9-1_記述ルール.md#10-列挙と行の書き方一覧表の共通ルール>) を正とする（各ページに重複記載しない）。

## 2. CRUD一覧

*参照資料（`Ⅳ-5.CRUD表.xlsx`）と同じマトリクス形式を採用する。*

- **行**：機能ごとにグループ化し、その機能に属する画面を並べる（1行＝1画面）。元Excelでは機能ID・
  機能名称を最初の行にのみ記載し縦方向にセル結合しているが、マークダウン表では**その機能に属する
  全ての行に同じ機能ID・機能名称を繰り返して記載**する（空欄にしない。上記「共通の記入ルール」を参照）。
- **列**：1列＝1物理テーブル。列見出しは「物理テーブル名」と「論理名」を`<span style="writing-mode:
  vertical-rl;">…</span>`で縦書き表示にし、横幅を抑える（元Excelの列見出し回転と同じ考え方）。DB内の
  全テーブルを対象とし、使用画面数が0件のテーブルも列を省略せず記載する（改修時にどのテーブルが
  未使用かを判別できるようにするため）。
- **交点**：その画面がそのテーブルに対して行うC/R/U/Dの組み合わせ（例："CRUD"、"RU"）を記載する。
  関係がない交点は空欄とする。

*同一機能に属する2画面目以降も、上表のように機能ID・機能名称の欄に同じ値を繰り返して記載し、
空欄にしない（マークダウン表にはExcelのようなセル結合が無いため）。列（テーブル）はDB内の全テーブル
分を展開するのが正式な方針だが、本ひな形では書式を示すため2列のみ例示している。*

## 3. 凡例

| 記号   | 意味                                                                     |
| ------ | ---------------------------------------------------------------------------- |
| C      | Create（そのテーブルにレコードを新規作成する）                            |
| R      | Read（そのテーブルを参照する）                                            |
| U      | Update（そのテーブルのレコードを更新する）                                |
| D      | Delete（そのテーブルのレコードを削除する）                                |
| CRUD等の組み合わせ表記 | その画面がそのテーブルに対して行う操作の組み合わせ（例："CRUD"＝C・R・U・D全て行う、"RU"＝参照と更新のみ） |
| 空欄   | その画面とそのテーブルの間に関係がない（一切アクセスしない）              |
