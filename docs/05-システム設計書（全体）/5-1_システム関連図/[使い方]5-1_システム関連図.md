# システム関連図 — 使い方

*記入用の様式は [空テンプレート](<[Template]5-1_システム関連図.md>)、記入例は [サンプル](<[Sample]5-1_システム関連図.md>) を参照。*

## 1. 参考様式

*全注（全注文システム）基本設計書 `Ⅳ-1.ｼｽﾃﾑ関連図.xlsx` の構成に合わせている。
見出し番号・表の列は全注の実ファイルのものを踏襲している。本システムで不要な列は削ってよい。*

## 2. 凡例

*全注の原本は、連携の線を3種類に描き分けている。本サイトでは Mermaid の線種で対応させる。*

| Mermaidの記法 | 線の見た目 | 連携区分 | 意味 |
| ------------- | ---------- | -------- | ---- |
| `A --> B` | 実線 | 既存 | 今後も残る既存の連携 |
| `A ==> B` | 太実線 | 新規・変更 | 本開発で新規に作る／変更する連携 |
| `A -.-> B` | 点線 | マニュアル | 手作業による連携（ファイル手渡し、画面転記など） |

*矢印には**連携するデータのファイルID／データ名**をラベルで付ける（例：`-->|FAZS122_注文一括取込データ|`）。
ファイルの詳細は [ファイル一覧](<../../06-システム設計書（一覧、管理台帳）/6-5_ファイル一覧/[Template]6-5_ファイル一覧.md>) を参照。*

*ノードの形は、本システムを `[[ ]]`（二重枠）、外部システムを `[ ]`（長方形）、
データベース参照を `[( )]`（円筒）で描き分ける。*

## 3. 各節の書き方

| 節 | 書くこと |
| -- | -------- |
| 1. システム関連図 | 本システムと周辺システムの関係を1枚の図で示す。`<-->` は双方向、片方向は向きを明示 |
| 2. 連携システム一覧 | **1行＝1システム**の俯瞰。データ単位の詳細（形式・手段・間隔）は [IF一覧](<../../06-システム設計書（一覧、管理台帳）/6-6_IF一覧/[Template]6-6_IF一覧.md>) を正とし、ここは「主な連携データ」の代表のみ（二重管理を避ける） |
| 3. 連携対象外としたシステム | 検討したが連携しないと判断したものを記録（全注は実績管理システムを「納期管理システム経由でDB参照するため直接連携しない」とした） |
