## 1. システムフロー図

### （対象部門：《部門名》）

#### 《フロー名》

```mermaid
flowchart TB
    subgraph 外部システムA[外部システムA]
        extProc[取込処理]
        extFile[/連携データ.TSV/]
    end

    doc([入力帳票]) --> screen1{{登録画面}}
    screen1 --> proc1[登録処理]
    proc1 --> db1[(データA)]
    proc1 --> db2[(データB)]

    screen2{{照会画面}} --> list1[一覧表示処理]
    db1 --> list1
    db2 --> list1

    list1 --> out1[データ出力処理]
    out1 --> file1[/連携データ.TSV/]
    file1 --> extFile
    extFile --> extProc
```

#### 《フロー名2》

```mermaid

    file2[/マスターデータ.TSV/] --> screen3{{取込画面}}
    screen3 --> proc3[取込処理]
    proc3 --> db3[(マスターデータ)]
```
