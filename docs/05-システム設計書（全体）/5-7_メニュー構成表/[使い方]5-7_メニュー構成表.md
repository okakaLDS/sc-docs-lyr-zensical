# メニュー構成表 — 使い方

*記入用の様式は [空テンプレート](<[Template]5-7_メニュー構成表.md>)、記入例は [サンプル](<[Sample]5-7_メニュー構成表.md>) を参照。*

## 1. 参考様式

*全注（全注文システム）基本設計書 `Ⅳ-7.ﾒﾆｭｰ構成表.xlsx` の構成に合わせている。
見出し番号・表の列は全注の実ファイルのものを踏襲している。本システムで不要な列は削ってよい。*

## 2. 凡例

| 記号 | 意味 |
| ---- | ---- |
| ● | 表示する |
| － | 表示しない |

## 3. 各節の書き方

| 節 | 書くこと |
| -- | -------- |
| メニュー階層 | 例：メニュー階層は1階層とする、等の方針 |
| メニュー構成表 | メニューグループごとの表示可否を定義。**列見出しにはグループ名とコード値を併記**（全注は「営業/CS(国内)＝10」「製造＝40」「管理者＝90」）。メニューグループのコード・名称は [ユーザーグループ（権限）一覧](<../5-8_ユーザーグループ（権限）一覧/[Template]5-8_ユーザーグループ（権限）一覧.md>) と一致させる。画面IDは [画面・帳票一覧](<../../06-システム設計書（一覧、管理台帳）/6-2_画面・帳票一覧/[Sample]6-2_画面・帳票一覧.md>) と一致させる |
| ヘッダーメニュー | 画面上部に常時表示するメニューがある場合に定義（無ければ節を削除） |
| 実装方針 | メニュー画面の実現方式（標準部品の流用／独自実装）、表示制御の方式、並び順の決め方 |

> **📌 この表に明細（long形式）を付けない理由**
>
> *CRUD表・共通機能一覧・排他マトリクスには検索用の明細を設けるが、本表には設けない。
> 列がメニューグループの数（数個〜十数個）に収まり、かつ全マスが埋まる密な表なので、行列のままでも取り違えにくいため。
> **列が10を超える、または空白が大半を占めるようになったら**明細節の追加を検討する。*
