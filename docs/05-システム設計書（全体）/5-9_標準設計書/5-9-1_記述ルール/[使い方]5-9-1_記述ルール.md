# 記述ルール — 使い方

*空テンプレートは [Template]記述ルール、本文（記載ルールの正）は [本文](<[Sample]5-9-1_記述ルール.md>) を参照。*

## 1. このドキュメントは何か

- 設計書を書くときの**表記の決まり**。ここで一度決めておけば、各設計書で毎回書かずに済む。
- **記載ルールの正**であり、各設計書はこのルールに従う。迷ったら本文を参照する。

## 2. 節の構成

| 節 | 内容 |
| -- | ---- |
| 1 | ドキュメントの構成（ファイル分割・文書情報・改定履歴の位置など） |
| 2 | Markdownの記法（使ってよい／いけない記法） |
| 3 | 図の書き方（Mermaid） |
| 4 | 表の書き方 |
| 5 | 用語・表記 |
| 6 | 画面設計の書き方 |
| 7 | ファイル出力の書き方 |
| 8 | 版数（Ver.）の付番ルール |
| 9 | 承認・捺印の運用 |

## 3. 維持のしかた

- ルールを変えるときは**本文（[Sample]）を更新**し、末尾の改定履歴に記録する。
- 影響範囲が大きい変更は、関連ドキュメント（`template-list.md` 等）とも整合させる。
