# システム共通仕様 — 使い方

*空テンプレートは [Template]システム共通仕様、本文（共通仕様の正）は [本文](<[Sample]5-9-2_システム共通仕様.md>) を参照。*

## 1. このドキュメントは何か

- **全画面・全機能に共通して適用する仕様**を1か所に集約したもの。
- 個別機能の仕様は各機能定義書に書き、**「どの機能でも同じ」ものだけ**を本ドキュメントに集約する。ここに書いたことは各設計書で繰り返さず、本ドキュメントを参照する。

## 2. 節に書くこと

| 節 | 書くこと |
| -- | -------- |
| 1 | チェック処理方針（画面/バッチ/連携での登録・更新、項目ごとの方針） |
| 2 | 画面レイアウト（全体）（ヘッダー項目・タブ表示名など） |
| 3 | 配色一覧（全体・ステータス別） |
| 4 | メッセージ（出力タイミング・文言ルール・非出力時） |
| 5 | 共通部品・共通挙動（部品が増える場合は1部品＝1ファイルに切り出す） |
