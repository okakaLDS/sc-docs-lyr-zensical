# 表紙 — 使い方

*本文（表紙の正）は [本文](<[Sample]1_表紙.md>)、空テンプレートは [Template]表紙 を参照。*

## 1. このドキュメントは何か

- **基本設計書ぜんたいの表紙**。システム名・章立て・承認欄／検収欄・改定履歴を載せる。
- **表紙の改定履歴が基本設計書ぜんたいの版管理を兼ねる**（各ドキュメント個別の改定は各ファイル末尾の改定履歴）。

## 2. 記入すること

| 節 | 書くこと |
| -- | -------- |
| 文書情報 | システム名・システムID・版数・作成日／更新日・プロジェクト名・計画書No. |
| 章立て（大項目） | 章の一覧（詳細な成果物単位は 基本設計成果物一覧 が正） |
| 承認欄・検収欄 | KCCSの承認欄／SC様の検収欄（押印枠は20mm角のCSS） |
| 改定履歴 | ぜんたいの版管理。承認した版・署名済みPDFの保管先などを備考へ |

## 3. PDF印刷・捺印の運用

- 承認された正＝「本文（表紙）をPDF印刷し、そのPDFに捺印したもの」。生きたMarkdownには印影を貼らない。
- 手順は [標準設計書 記述ルール 節9（承認・捺印の運用）](<../05-システム設計書（全体）/5-9_標準設計書/5-9-1_記述ルール/[Sample]5-9-1_記述ルール.md>) を参照。
- **印刷はビルドしたサイト経由**で行う（VSCodeプレビューからPDF化すると押印枠が出ない）。署名済みPDFは社内保管とし **Public GitHubには置かない**。
